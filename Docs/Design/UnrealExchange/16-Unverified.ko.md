## 16. 미확인 항목

| 항목 | 확인 시점 |
|---|---|
| UE가 같은 이름 파라미터 노드의 기본값이 다를 때 쓰는 값 | UX4b |
| 정적 메시 정점 버퍼 생성의 퇴화·용접 임계값 상수 값(Rocks 상수로 옮김) | MA2·UX3b |
| Substrate가 꺼진 프로젝트에서 저장된 `BLEND_TranslucentColoredTransmittance`가 로드 경로에서도 `Translucent`로 그려지는지(UE는 `PostEditChangeProperty`에서만 바꾼다 — 8.8절 3번) | UX5a |
| 함수 소유 Substrate slab의 `SubSurfaceType` 로드 변환이 처음 로드한 머티리얼에 따라 달라지는지, 내보내기 선택이 다르면 함수 덤프가 달라지는지(8.8절 4번) | UX5a |
