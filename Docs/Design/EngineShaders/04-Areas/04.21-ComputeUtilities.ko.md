# 엔진 셰이더 — 4.21 컴퓨트 유틸(A21)

[4장 목차](README.ko.md)

### 4.21 컴퓨트 유틸(A21)

**역할.** 렌더러와 GPU 작업이 함께 쓰는 병렬 기본 연산: 그룹 안·전역 prefix sum(scan), 축소(합·최소·최대), 정렬(bitonic·radix), 작업 분배·부하 분산, GPU 해시 표, 이진 탐색, 비트 스트림 읽기, 2×2 픽셀 quad 사이 값 교환, 블록 압축(BC·ETC·ASTC) 부호화.

**UE 파일(15).** `ThreadGroupPrefixSum.ush`, `ReductionCommon.ush`, `BitonicSort.usf`, `RadixSortShaders.usf`, `WorkDistribution.ush`, `WorkGroupLoadBalancer.ush`, `HashTable.ush`, `BinarySearch.ush`, `BitStreamReaderImplementation.ush`, `PixelQuadMessagePassing.ush`, `BlockCompressionCommon.ush`, `BCCompressionCommon.ush`, `ETCCompressionCommon.ush`, `ASTCCompressionCommon.ush`, `IntegerSequenceEncoding.ush`. (FFT `GPUFastFourierTransform*`는 FFT bloom과 함께 A24.)

**의존.** A01(`WaveOperations.rsh` — 웨이브 있는 형식과 groupshared 대체가 같은 결과), A02(해시·Morton). 쓰는 곳: A08(light grid prefix sum), A06(인스턴스 압축·간접 인자), A17(histogram 축소), A18(밉 생성 축소), 투명 정렬(GPU 정렬로 옮길 때), 후속 VFX(입자 정렬), 텍스처 런타임 압축(VT·render target 압축 — 후속).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Compute/GroupPrefixSum.rsh` | 그룹 안 exclusive·inclusive scan(웨이브 경로와 groupshared 경로 결과 동일) | SL3 |
| `Compute/GlobalPrefixSum.rsf` | 큰 배열 scan(그룹 합 → 그룹 합의 scan → 더하기, 세 dispatch. 한 pass 방식(decoupled look-back)은 forward progress 보장이 없는 GPU가 있어 1차에서 쓰지 않는다) | SL3 |
| `Compute/GroupReduction.rsh` | 그룹 축소(합·최소·최대·개수), 2D 타일 축소 | SL3 |
| `Compute/WorkDistribution.rsh` | 가변 크기 작업 목록 → 고정 그룹에 균등 분배(prefix sum + 이진 탐색), 그룹 부하 분산 | SL6 |
| `Compute/BinarySearch.rsh` | 정렬 배열 상한·하한 탐색 | SL6 |
| `Compute/BitonicSort.rsf` | 그룹 안·전역 bitonic 정렬(키·값), 작은 배열용 | SL6 |
| `Compute/RadixSort.rsf` | 4 bit 단위 radix 정렬(개수 → scan → 흩기), 큰 배열용. 결정성: 같은 키의 순서 보존(안정 정렬) | SL6 |
| `Compute/GpuHashTable.rsh` | 열린 주소 해시 표(원자 비교-교환 삽입, 해시는 A02) | 후속(쓰는 기능과 함께) |
| `Compute/BitStreamReader.rsh` | 가변 비트 폭 스트림 읽기(압축 데이터 해독) | 후속 |
| `Compute/QuadMessaging.rsh` | 2×2 quad 사이 값 교환(`ddx_fine`·`ddy_fine`·quad 읽기), 미분 기반 대체 | SL8 |
| `Compute/BlockCompressionBc.rsh`·`BlockCompressionEtc.rsh`·`BlockCompressionAstc.rsh` | 런타임 BC1–BC7·ETC2·ASTC 부호화(블록 끝점 찾기·색인 양자화, ASTC 정수열 부호화) | 후속(런타임 텍스처 압축 — VT·render target 압축) |

**단계.** SL3(scan·축소 — RN RS1 light grid), SL6(분배·정렬 — RN RS4), SL8(quad 교환), 후속(해시 표·비트 스트림·블록 압축).
