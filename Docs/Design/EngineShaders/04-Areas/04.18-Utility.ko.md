# 엔진 셰이더 — 4.18 유틸리티(A18)

### 4.18 유틸리티(A18)

**역할.** 렌더 그래프·렌더 기반이 쓰는 범용 pass: 전체 화면 삼각형, 텍스처·깊이 복사(차원·형식·채널 변환 포함), 버퍼 scatter·복사·채움, UAV·렌더 타깃 clear, compute 밉 생성, 분리 Gaussian 필터, MSAA resolve, 깊이 다운샘플, 간접 인자 준비, 텍스처 표본 보조, 텍스처 readback 변환, 단색·자리표시 셰이더.

**UE 파일(37).** `ScreenVertexShader.usf`, `ScreenPixelShader.usf`, `ScreenPixelShaderOES.usf`, `Tools/FullscreenVertexShader.usf`, `FilterVertexShader.usf`·`FilterPixelShader.usf`, `CopyTextureShaders.usf`, `CopyDepthTexture.usf`·`CopyDepthTextureCS.usf`, `ClearReplacementShaders.usf`, `OneColorShader.usf`, `ComputeGenerateMips.usf`, `ResolveVertexShader.usf`·`ResolvePixelShader.usf`, `HdrCustomResolveShaders.usf`, `WideCustomResolveShaders.usf`·`WideCustomResolve_Wide.ush`·`_Wider.ush`·`_Widest.ush`, `DownsampleDepthPixelShader.usf`, `ByteBuffer.usf`·`ByteBuffer.ush`, `CopyUIntBuffer.usf`, `UpdateTextureShaders.usf`, `RenderGraphUtilities.usf`, `RendererUtils.usf`, `Tools/SetupIndirectArgs.usf`, `Tools/DrawTexture.usf`, `Tools/DumpTexture.usf`, `TextureSampling.ush`, `PostProcessPassThrough.usf`, `PostProcessChannelMask.usf`, `PostProcessAlphaInvert.usf`, `NullPixelShader.usf`, `SolidColorPixelShader.ush`(+`.tps`), `MissingShaderPixelShader.usf`.

**의존.** A01·A02·A03(sRGB 정확 필터). 렌더러·렌더 기반: RB 11.2절(전체 화면 pass·clear·MSAA resolve 규칙), RB 6.3절(내장 자원 팩 — 밉·cube), RG1·RG2(그래프 복사·업로드), 화면 마일스톤(RB 18.1절: 다섯 차원 텍스처 표시), RN RS8(MSAA).

**들이지 않는 것(지금).** 넓은 필터 MSAA resolve(`WideCustomResolve*` — 넓은 커널 resolve, RS8 측정 뒤 후속), Android OES 외부 텍스처 복사(`ScreenPixelShaderOES.usf` — 카메라·미디어 텍스처, A35 미디어와 함께 후속), 텍스처 영역 갱신 compute(`UpdateTextureShaders.usf` — Graphics 복사 명령으로 충분, 필요할 때).

**단계.** SL1(화면 마일스톤: 전체 화면·복사·clear·밉·표본 보조·자리표시·readback 변환), SL2(버퍼 업로드), SL3(간접 인자), SL8(Gaussian·깊이 다운샘플), SL10(MSAA resolve).

**근거 문헌.** 정점 번호로 화면을 덮는 삼각형 하나를 만드는 방식은 널리 쓰이는 기법이다(RB 11.2절이 채택); Catmull, Rom, *A Class of Local Interpolating Splines*, 1974; AMD, *FidelityFX Single Pass Downsampler*(공개 문서 — 한 dispatch 여러 mip); Pettineo, *Experimenting with Reconstruction Filters for MSAA Resolve*, 2012(resolve 필터 배경).
