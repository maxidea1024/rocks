# 엔진 셰이더 — 4.6 장면 데이터·view·컬링·HZB(A06)

[4장 목차](README.ko.md)

### 4.6 장면 데이터·view·컬링·HZB(A06)

**역할.** view 상수 접근, 깊이 ↔ view Z·위치 복원(reversed-Z 무한 원평면), 장면 텍스처(깊이·SceneColor·GBuffer·velocity·custom depth) 읽기, GPU Scene 인스턴스·primitive 기록 읽기와 갱신 업로드, HZB 생성과 HZB 가림 판정, GPU 인스턴스 컬링·압축·간접 그리기 인자, LOD 전환 dither.

**UE 파일(31).** `CommonViewUniformBuffer.ush`, `ViewData.ush`, `SceneData.ush`, `SceneTextureParameters.ush`, `SceneTexturesCommon.ush`, `PositionReconstructionCommon.ush`, `GPUScene/GPUSceneDataManagement.usf`·`GPUSceneWriter.ush`, `HZB.usf`·`HZB.ush`, `HZBOcclusion.usf`, `HZBTracing.ush`, `InstanceCulling/`(7: 그리기 명령 생성·가시 인스턴스 압축·부하 분산·가림 질의·설정), `SceneCulling/`(3: 셀 기반 계층 컬링·명시 bounds·디버그), `OcclusionQueryVertexShader.usf`·`OcclusionQueryPixelShader.usf`, `DitheredTransitionStencil.usf`, `GenerateConservativeDepth.usf`, `Shared/SceneDefinitions.h`·`ViewDefinitions.h`·`InstanceCullingDefinitions.h`·`SceneCullingDefinitions.h`·`EnvironmentComponentsFlags.h`.

**의존.** A01·A02. 쓰는 곳: 모든 pass. 렌더러: RN 5절(view·가시성 V1–V5), 6.2절 F1·F2·F4·F5, RS0(GPU Scene·HZB), RS4(2단계 가림·GPU 인스턴스 컬링·간접 draw), RB 10.5절(인스턴스 데이터 읽기), RB 9.5절(공유 상수 slot — view 상수).

**Rocks 파일.**

**들이지 않는 것(지금).** 하드웨어 가림 질의(`OcclusionQuery*`, `InstanceCullingOcclusionQuery.usf`) — Rocks 가림은 HZB 2단계(RN V2–V4)다. 질의 방식이 필요해지면 후속. 셀 기반 GPU 장면 컬링(`SceneCulling/`) — 인스턴스가 매우 많을 때의 계층 컬링으로, RS4 측정 뒤 후속. `GenerateConservativeDepth.usf` — Nanite HZB용(A26 후속).

**단계.** SL1(깊이 변환 일부), SL2(view·장면 텍스처·GPU Scene·HZB 생성 — RN RS0), SL6(가림·인스턴스 컬링·LOD dither — RN RS4), SL10(HZB 화면 추적 — RN RS10).

**근거 문헌.** Greene, Kass, Miller, *Hierarchical Z-Buffer Visibility*, SIGGRAPH 1993; Haar, Aaltonen, *GPU-Driven Rendering Pipelines*, SIGGRAPH 2015 Advances; Wihlidal, *Optimizing the Graphics Pipeline with Compute*, GDC 2016; Reed, *Depth Precision Visualized*, NVIDIA 2015(reversed-Z); Upchurch, Desbrun, *Tightening the Precision of Perspective Rendering*, JGT 2012.
