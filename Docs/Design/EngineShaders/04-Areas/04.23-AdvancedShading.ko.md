### 4.23 고급 셰이딩 모델(A23)

**역할.** MS 표면 범위 SF3(RN RS9)의 shading model 평가와 그 보조 pass: `ClearCoat`(2차 반사층), `Subsurface`·`TwoSidedFoliage`(wrap·투과), `SubsurfaceProfile`(화면 공간 SSS — Burley 정규화 확산·분리형 SSS, profile atlas), `Cloth`(sheen), `Eye`(홍채 굴절·각막), `ThinTranslucent`(얇은 투명 투과), `SingleLayerWater`(물 흡수·산란·굴절, 합성 pass), specular profile(반사 색 LUT). 투과 두께(그림자 depth로 두께 추정)도 여기다.

**UE 파일(19).** `PostProcessSubsurface.usf`·`PostProcessSubsurfaceCommon.ush`·`PostProcessSubsurfaceDiffuse.usf`·`PostProcessSubsurfaceDiffuse.ush`·`PostProcessSubsurfaceTile.usf`, `SubsurfaceBurleyNormalized.ush`, `BurleyNormalizedSSSCommon.ush`, `SeparableSSS.ush`(+`.tps`), `SubsurfaceProfileCommon.ush`, `TransmissionThickness.ush`, `ThinTranslucentCommon.ush`, `SingleLayerWaterCommon.ush`·`SingleLayerWaterShading.ush`·`SingleLayerWaterComposite.usf`·`SingleLayerWaterRefractionCulling.usf`, `SpecularProfile.usf`·`SpecularProfileCommon.ush`, `Shared/SingleLayerWaterDefinitions.h`. (고전 경로 `ClearCoatCommon.ush`·`TransmissionCommon.ush`는 A04 분류.)

**UE 근거 주의.** 4.4절과 같다: shading model별 고전 평가 함수는 5.7 deprecated이고, Rocks는 Substrate 단일 slab 평가의 역할·입출력과 공개 문헌으로 구현한다(결정 SLD3).

**의존.** A04(BRDF 항·`SurfaceShading`), A07(GBuffer D — MRT 8 형식만, RN 결정 RN3·RN4), A09(조명 함수 분기), A10(투과 두께는 그림자 depth), A11(물 반사), A15(굴절), A16(물 아래 안개 계수), A18(분리 필터). 렌더러: RN 14.2절 shading model 번호, RS9. 머티리얼: MS MS8(SF3).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Shading/ClearCoatShading.rsh` | 2층 평가(위층 GGX + Fresnel 감쇠 → 아래층), 위층 법선 선택 | SL10 |
| `Shading/SubsurfaceShading.rsh` | wrap 확산·투과(그림자 두께 기반 소광), TwoSidedFoliage 뒷면 투과 | SL10 |
| `Shading/TransmissionThickness.rsh` | 그림자 depth로 표면 두께 추정(보통 Z 규약) | SL10 |
| `Shading/ClothShading.rsh` | sheen(Charlie 분포·Ashikhmin 근사)·fuzz 색 | SL10 |
| `Shading/EyeShading.rsh` | 각막 반사 + 홍채 굴절 깊이·오목, 홍채 법선 | SL10 |
| `Shading/ThinTranslucentShading.rsh` | 얇은 층 투과 색·반사(유전체 Fresnel), 투명 pass 전용 | SL10 |
| `Shading/SpecularProfile.rsh`·`BuildSpecularProfileAtlas.rsf` | 시선·광원 각 → 반사 색 LUT atlas | SL10 |
| `Subsurface/SubsurfaceProfiles.rsh`·`BuildSubsurfaceProfileAtlas.rsf` | profile 파라미터(산란 반경·색·경계 혼합) → atlas(Burley 커널 표본 표·분리형 커널) | SL10 |
| `Subsurface/ScreenSpaceSubsurface.rsf` | 확산 조명 분리 출력(A04 `LightAccumulation`) → 타일 분류 → Burley 정규화 확산 중요도 표본 또는 분리형 2-pass → 재합성(반사는 그대로) | SL10 |
| `Water/SingleLayerWaterShading.rsh` | 물 표면: 흡수·산란 계수, 반사(SSR·capture), 굴절(화면 SceneColor·깊이), 물속 안개 | SL10 |
| `Water/SingleLayerWaterComposite.rsf` | 물 아래 장면 + 물 표면 합성, 굴절 타일 컬링 | SL10 |
| `Shared/WaterLayout.h` | 3.3절 | SL10 |

**들이지 않는 것.** `Hair`(HairBsdf·HairShadingCommon — A32, P3 gate), 미리 적분된 피부(UE `PreintegratedSkin` — RN 14.2절이 `SubsurfaceProfile`로 받기로 함).

**단계.** SL10(RN RS9, MS MS8).
