# 엔진 셰이더 — 4.1 플랫폼·공통 매크로(A01)

[4장 목차](README.ko.md)

### 4.1 플랫폼·공통 매크로(A01)

**역할.** 모든 셰이더가 먼저 보는 머리다. 형식·컴파일러·단계 판정, 기능 매크로, 수학 상수와 아주 작은 보조, 단계 출력 구조, compute 스레드 번호 보조, 웨이브 연산과 그 대체, 상수 버퍼의 스칼라 배열 접근, GPU assert, C++·HLSL 공용 헤더의 기반.

**UE 파일(26).** `Public/Platform.ush`, `Public/Platform/D3D/D3DCommon.ush`·`D3DRootConstants.ush`, `Public/Platform/GL/GLCommon.ush`, `Public/Platform/Metal/MetalCommon.ush`, `Public/Platform/Vulkan/VulkanCommon.ush`, `Public/ShaderVersion.ush`, `Public/OverloadMacros.ush`, `Public/FP16Math.ush`, `Public/RootConstants.ush`, `Public/WaveBroadcastIntrinsics.ush`, `Public/LaneVectorization.ush`, `Public/DualPixelVectorization.ush`, `Common.ush`, `Definitions.usf`, `AssertionMacros.ush`, `GeneratedUniformBufferTypes.ush`, `ComputeShaderUtils.ush`, `ComputeShaderOutputCommon.ush`, `PixelShaderOutputCommon.ush`, `ShaderOutputCommon.ush`, `WaveOpUtil.ush`, `Shared/HLSLTypeAliases.h`·`HLSLMathAliases.h`·`HLSLStaticAssert.h`·`HLSLReservedSpaces.h`.

**UE 구조 메모.** `Common.ush`는 플랫폼 머리 다음에 수학 상수, `View`·장면 텍스처 선언, 깊이 변환, 화면 좌표 변환, 여러 보조를 한 파일에 담는다. `Definitions.usf`는 정의되지 않은 기능 매크로에 기본값 0을 준다. `ShaderVersion.ush`는 전체 재컴파일을 강제하는 GUID다(Rocks는 SS 키가 원문 내용 SHA-256이라 필요 없다). `LaneVectorization`·`DualPixelVectorization`은 half 2개 묶음 계산용 고급 최적화다.

**의존.** 모든 영역이 쓴다. A01 파일은 `Platform.rsh`·`ShaderFeatures.rsh`만 include한다. 예외는 묶음 파일 `ShaderPrelude.rsh` 하나로, A02의 `Math/MathConstants.rsh`·`Math/ScalarMath.rsh`를 함께 include한다(두 파일은 A01만 쓰는 순수 함수라 순환이 없다).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Public/Platform.rsh` | (있음, SH1a) 형식·컴파일러·단계 정의 검사, `ROCKS_SPIRV`, `ROCKS_IMAGE_FORMAT` | 구현 |
| `Public/ShaderFeatures.rsh` | 형식 기능 → `ROCKS_FEATURE_COMPUTE`·`ROCKS_FEATURE_WAVE_OPERATIONS`·`ROCKS_FEATURE_TYPED_UAV_LOAD`·`ROCKS_FEATURE_DEBUG_PIXEL_UAV`(늘 0·1로 정의). SC10이 내보내기 전에는 형식 id 임시 표(웨이브는 `D3D12_SM6`만 1 — 3.2절, 9.3절 SLR1·SLR12) | SL0 |
| `Private/Common/ShaderPrelude.rsh` | 모든 라이브러리·엔트리가 처음 include하는 작은 묶음. include 목록은 정확히 넷: `Public/ShaderFeatures.rsh`, `Private/Common/ShaderAssert.rsh`, `Private/Math/MathConstants.rsh`, `Private/Math/ScalarMath.rsh`. view·장면 텍스처는 넣지 않는다(UE `Common.ush`와 다른 점, 결정 SLD2) | SL0 |
| `Private/Common/ShaderAssert.rsh` | 개발 빌드 GPU assert(조건 실패 시 `Debug/GpuMessages.rsh` 버퍼에 파일·줄 기록, Release에서는 빈 것). CS에서는 기록한다. VS·PS에서는 `ROCKS_FEATURE_DEBUG_PIXEL_UAV`가 있는 형식·개발 빌드에서만 기록하고, 없는 형식(D3D11·GLES 포함)에서는 아무것도 하지 않는다(SS 7.2절 — VS·PS UAV 금지, 결정 SLD18) | SL0(빈 매크로)·SL2(기록) |
| `Private/Common/StageOutputs.rsh` | MRT 출력 구조체를 선언하는 매크로(렌더 타깃 수·형식별 출력 타입), `SV_Depth` 변형(conservative depth 포함) | SL0 |
| `Private/Common/ComputeDispatch.rsh` | **CS 전용 API.** 그룹·스레드 번호 → 선형·2D 좌표, 큰 그룹 수의 그룹 번호 풀기(그룹 수 상한 65,535 우회), 간접 dispatch 인자 계산, 타일 순회(Morton 순서는 A02). CS 밖에서 include하면 `#error` | SL1(GX3·GX4 dispatch 뒤) |
| `Private/Common/WaveOperations.rsh` | **CS 전용 API**(groupshared 대체가 CS에만 있으므로). 그룹 단위 합·최소·최대·prefix·broadcast. `ROCKS_FEATURE_WAVE_OPERATIONS`가 1인 형식(지금은 `D3D12_SM6`뿐)은 웨이브 intrinsic + 웨이브 사이 groupshared 합성, 나머지는 groupshared만으로 **같은 결과**를 낸다(결정 SLD5). 웨이브 크기를 가정하지 않는다 | SL1(GX3·GX4 dispatch 뒤) |
| `Private/Common/ScalarArrays.rsh` | float4 배열로 묶은 스칼라 배열의 원소 접근(SS 7.2절 5항 배열 규칙) | SL0 |
| `Private/Common/RootConstants.rsh` | `ROCKS_ROOT_CONSTANTS` 사용 보조(SS 7.2절 2항 전개는 `Platform.rsh` 소관이므로 여기서는 읽기 보조만). SL0에서는 만들지 않았다(개정 3 — `Platform.rsh` 매크로와 구조체 멤버 읽기로 충분하고 7.2절 SL0 목록에도 없다). 읽기 보조가 필요한 pass가 생기면 그때 만든다 | 필요할 때 |
| `Shared/ShaderTypeAliases.h`·`ShaderStaticAssert.h`·`ReservedBindingSpaces.h` | 3.3절 | SL0 |

**들이지 않는 것.** `ShaderVersion.ush`(키가 내용 해시), `OverloadMacros.ush`(HLSL 2021 템플릿·오버로드로 대신 — HLSL 2021이 꺼진 `D3D11_SM5`·GLES 형식에서도 컴파일돼야 하므로 라이브러리는 오버로드를 손으로 쓴다), `LaneVectorization`·`DualPixelVectorization`·`FP16Math`(결정 SLD4: half는 1차 미사용, 후속 측정 뒤), `Definitions.usf`(Rocks는 정의되지 않은 매크로를 0으로 두지 않는다 — 기능 매크로는 `ShaderFeatures.rsh`가 늘 정의한다).

**단계.** SL0(SH2와 함께 — 위 표에서 SL0인 것), SL1(CS 전용 `ComputeDispatch`·`WaveOperations` — compute probe가 생기는 GX3·GX4 뒤), SL2(GPU assert 기록).

**근거 문헌.** Microsoft, *HLSL Shader Model 6.0 Wave Intrinsics* 명세; Khronos, *SPIR-V Specification* subgroup 연산; Microsoft, *DirectX-Specs: HLSL 2021*.
