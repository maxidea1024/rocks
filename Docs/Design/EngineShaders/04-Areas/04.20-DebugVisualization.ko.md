### 4.20 디버그·시각화·편집 표시(A20)

**역할.** 개발·편집 빌드의 GPU 진단과 표시: 셰이더 안 글자·숫자·선 출력(GPU print), GPU → CPU 메시지(assert·통계), 디버그 view mode(셰이더 복잡도·quad overdraw·라이트맵 밀도·텍스처 표본 정확도·wireframe), 버퍼 시각화(GBuffer 채널·HDR·velocity·깊이), 텍스처 검사기, shading model·볼륨 라이트맵·정지 광원 겹침 시각화, 광원 모양, 편집 표시(선택 외곽선·편집·디버그 단순 요소 합성·hit proxy·mesh edge·메시 칠하기·level instance 편집 표시), 디버그 선 묶음과 아이콘 sprite(RN RS13), 색 보정 도구(histogram·parade·vectorscope).

**UE 파일(47).** `ShaderPrint.ush`·`ShaderPrintCommon.ush`·`ShaderPrintDraw.usf`·`ShaderPrintDrawPrimitive.usf`, `MiniFontCommon.ush`, `PrintValue.ush`(+`.tps`), `GPUMessaging.usf`·`GPUMessaging.ush`, `DebugViewModeCommon.ush`·`DebugViewModePixelShader.usf`·`DebugViewModeVertexShader.usf`, `ShaderComplexityApplyPixelShader.usf`, `QuadOverdraw.ush`, `QuadComplexityAccumulatePixelShader.usf`, `LightMapDensityShader.usf`, `VisualizeShadingModels.usf`, `VisualizeVolumetricLightmap.usf`, `StationaryLightOverlapShaders.usf`, `Visualization.ush`, `PostProcessVisualizeBuffer.usf`·`PostProcessVisualizeHDR.usf`·`PostProcessVisualizeDOF.usf`·`PostProcessVisualizeLocalExposure.usf`·`PostProcessVisualizeLevelInstance.usf`, `PostProcessGBufferHints.usf`, `PostProcessTestImage.usf`, `PostProcessSelectionOutline.usf`, `PostProcessCompositePrimitives.usf`, `HitProxyVertexShader.usf`·`HitProxyPixelShader.usf`·`HitProxyCopy.usf`, `MeshEdges.usf`, `GPUSceneDebugRender.usf`, `DebugProbes.usf`, `MeshPaintVertexShader.usf`·`MeshPaintPixelShader.usf`·`MeshPaintTextureCommon.ush`·`meshpaintdilatevertexshader.usf`·`meshpaintdilatepixelshader.usf`, `Tools/VisualizeTexture.usf`·`VisualizeLightShape.usf`·`DebugAlphaChannel.usf`·`ColorGradingHistogram.usf`·`ColorGradingParade.usf`·`ColorGradingVectorScope.usf`·`GPUDebugCrashUtils.usf`.

**의존.** A01·A02·A03(색 지도)·A06(장면 텍스처)·A07(GBuffer 해독)·A18(전체 화면)·A19(단순 요소). 렌더러: RN 4.2절·RS13(디버그·편집 표시, PC9a·PC9b), RN 16.2절(계측), 화면 마일스톤(텍스처 표시 — RB 18.1절). 컴포넌트: `ArrowComponent`·`BillboardComponent`·`DrawFrustumComponent`·`DrawSphereComponent`·`LineBatchComponent`·`DebugDrawComponent`(CC CM2·CM3), 내비·AI 디버그 표시(CC CM16).

**단계.** SL1(텍스처 검사기), SL2(GPU 메시지·print·버퍼 시각화), SL3·SL9(조명 시각화), SL10(RN RS13 편집·디버그 표시), 후속(편집기 도구).

**근거 문헌.** Akenine-Möller, Haines, Hoffman 외, *Real-Time Rendering* 4판 23장(2×2 quad 단위 픽셀 셰이딩과 overdraw 비용); Sobel, Feldman, *A 3×3 Isotropic Gradient Operator for Image Processing*, 1968(외곽선 가장자리 검출); Mikhailov 2019(Turbo, A03 참조). GPU print·메시지 버퍼는 원자 증가 append 버퍼라는 일반 기법이라 특정 문헌에 기대지 않는다.
