# 엔진 셰이더 — 4.5 머티리얼 템플릿·정점 입력(A05)

[4장 목차](README.ko.md)

### 4.5 머티리얼 템플릿·정점 입력(A05)

**역할.** 머티리얼 번역 결과(생성 파일)와 pass 원문을 잇는 정적 틀, 머티리얼 노드가 부르는 함수 모음, 머티리얼 텍스처 표본 보조(mip bias·법선 맵 복원), 그리고 정점 입력 타입(UE vertex factory) — 정점 입력 함수 인터페이스, 엔진 기본 타입, 로컬 메시 타입(정적·인스턴스·동적 메시), spline 변형.

**UE 파일(13).** `MaterialTemplate.ush`, `MaterialTexture.ush`, `MinMaterialTexCoords.ush`, `VertexFactoryCommon.ush`, `VertexFactoryDefaultFwd.ush`, `VertexFactoryDefaultInterface.ush`, `LocalVertexFactory.ush`, `LocalVertexFactoryCommon.ush`, `SplineMeshCommon.ush`, `SplineMeshSceneTexture.usf`, `DynamicMeshBounds.usf`·`DynamicMeshBounds.ush`, `Shared/SplineMeshShaderParams.h`.

**UE 구조 메모.** `MaterialTemplate.ush`는 번역기가 `%s` 자리에 코드를 넣는 텍스트 템플릿이고, 픽셀·정점 파라미터 구조체, 수백 개의 머티리얼 노드 보조 함수, 장면 텍스처 읽기를 한 파일에 담는다. 정점 팩토리는 `/Engine/Generated/VertexFactory.ush`로 연결되며 정해진 함수 집합(입력 구조체, world 위치, 보간 값 채우기, 이전 위치)을 구현한다.

**Rocks 차이.** 텍스트 치환이 없다(MS 7.2절): 정적 `MaterialCommon.rsh` + 생성 `/Engine/Generated/Material.rsh`가 정해진 이름의 함수(MS 7.3절 계약)를 낸다. 노드 보조 함수는 템플릿에서 떼어 `MaterialNodeLibrary.rsh`로 둔다. 정점 입력은 `/Engine/Generated/VertexInput.rsh` 연결(RB 10.2절)이다.

**의존.** A01·A02·A06(view 상수·GPU Scene 인스턴스 읽기). 쓰는 곳: 모든 메시 pass(A07·A10·A15·A13 mesh decal). 머티리얼 시스템 MS2(코드 생성)·MS4(Renderer 연결)와 짝이다.

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Material/MaterialCommon.rsh` | (MS 7.2절이 이름을 정함) `MaterialVertexInputs`·`MaterialInputs`·`MaterialVertexResult` 구조체, 생성 파일 include, 기본값 함수 | SL2 |
| `Material/MaterialNodeLibrary.rsh` | 노드 보조: Fresnel 노드, sphere mask, depth fade, 화면 위치·픽셀 깊이, world 정렬·triplanar, 회전·panner, 시간, 잡음(A02 `ProceduralNoise`), 법선 블렌드. 노드 묶음(MS 5.7절) 1차 범위에 맞춘다 | SL2 |
| `Material/MaterialTextureSampling.rsh` | view mip bias 적용 표본(RN 11.2절), 법선 맵 복원(2채널 → Z), 쿠킹된 텍스처 sampling scale 적용(MS 12.5절 — 값은 쿠킹 때 정해지고 셰이더는 읽기만 한다, PS UAV 쓰기 없음), 미분 지정 표본 | SL2 |
| `VertexInput/VertexInputInterface.rsh` | 정점 입력 타입이 구현할 함수 목록(입력 구조체 → `MaterialVertexInputs` 채우기, translated world 위치, 이전 위치, 보간 값 묶기·풀기). RB 10.2절 "첫 메시 셰이더 착수 전에 정한다"의 Rocks 확정 자리(MS 16절 MRB3) | SL2 |
| `VertexInput/VertexInputCommon.rsh` | local → translated world 변환(GPU Scene 인스턴스 기록, RB 10.5절), 이전 프레임 변환, 패킹 tangent 기저 복원(RB 10.4절 형식), 음수 행렬식 tangent 부호 | SL2 |
| `VertexInput/BuiltinVertexInput.rsh` | 엔진 기본 정점 입력 타입(위치·UV·색, RB 10.2절 (2)) — 내장 메시·fallback 셰이더 | SL1 |
| `VertexInput/LocalMeshVertexInput.rsh` | 로컬 메시 타입: 위치·패킹 법선·UV 채널(최대 수 이름 있는 상수)·정점 색·라이트맵 UV, 인스턴스 데이터(인스턴스드 메시·HLOD·식생도 같은 타입). 동적 메시(프레임 업로드 정점 — 머티리얼 billboard·text render·procedural·cable)도 이 타입을 인스턴스 없이 쓴다(UE도 동적 메시에 로컬 정점 팩토리를 쓴다) | SL2(정적·동적)·SL6(인스턴스) |
| `VertexInput/SplineMeshDeform.rsh` | spline 메시 변형: 메시 축을 따라 Hermite 곡선으로 휘기, roll·scale 보간, 법선·tangent 변형(파라미터 배치는 `Shared/SplineMeshLayout.h`) | SL6 |

**들이지 않는 것(지금).** `SplineMeshSceneTexture.usf`(spline 파라미터를 장면 텍스처로 — Nanite spline용, A26 후속), `DynamicMeshBounds.*`(GPU 변형 메시 bounds — 변형 그래프 후속), `MinMaterialTexCoords.ush`(UV 채널 수는 생성 파일 정의 `MATERIAL_NUM_TEXCOORDS`가 정한다).

**단계.** SL1(기본 정점 입력), SL2(머티리얼 틀·노드 라이브러리·로컬 메시 — RN RS0, MS4), SL6(인스턴스·spline — RN RS4, CC CM6).

**근거 문헌.** Mikkelsen, *Simulation of Wrinkled Surfaces Revisited*(MikkTSpace), 2008; Barré-Brisebois, Hill, *Blending in Detail*, 2012(법선 블렌드); Golus, *Normal Mapping for a Triplanar Shader*, 2017; Akenine-Möller, Haines, Hoffman 외, *Real-Time Rendering* 4판 6장(텍스처 표본·mip bias).
