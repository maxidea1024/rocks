### 2.2 저작권·출처 규칙

- Rocks 셰이더 원문은 공개 문헌(논문·발표·표준 문서)과 Rocks가 쓴 CPU 기준 구현을 보고 쓴다. UE 원문을 열어 놓고 옮겨 쓰지 않는다. 구현자는 UE 파일에서 **무엇을 하는가**(입력·출력·자리)만 확인한다.
- UE 셰이더 안의 서드파티 코드(1.1절)는 원 저작자의 공개 문서로 구현한다. 원 저작자의 참조 구현을 저장소에 들일 필요가 생기면 SS 8절 ThirdParty 절차(라이선스 기록·manifest)를 따르고, 시험 대조 자료로만 쓴다(결정 SLD8).
- 각 Rocks 원문 파일 머리 주석에 근거 문헌을 적는다(한국어 주석, 문헌 제목은 원어). 상수 표(예: ACES 행렬, 색각 이상 행렬, CIE 값)는 표준 문서나 논문에서 다시 계산하고 그 출처를 적는다.

### 2.4 비요구

- UE 원문과 결과가 bit 단위로 같을 필요는 없다. 같은 알고리즘·같은 파라미터 의미·허용 오차 안의 같은 영상이 목표다(RN 기준 영상 규칙).
- UE의 셰이더 파일 구성(파일 나눔·이름)을 따를 필요는 없다. 역할 단위로 다시 나눈다(3장).
- UE 콘솔 변수 이름·기본값은 CVar 문서가 정한다. 이 문서는 셰이더가 읽는 상수만 정한다.
