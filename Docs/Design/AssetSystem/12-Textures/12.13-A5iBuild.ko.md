### 12.13 A5i 구현 명세 — 텍스처 빌드(2026-11-24, 착수 전)

이 절은 12.5절 빌드 규칙을 TextureTools 함수로 구현하는 방법을 정한다(12.7절 A5i).
- 규칙 자체(적용 순서·Lanczos3·mip·LOD 합성)는 12.5절, 색 해석·출력 부호화·양자화는 12.2절 1–5번, 출력 형식·swizzle은 12.4.3절이다. 이 절은 그 규칙을 코드로 옮길 때 남는 선택(입력·출력 구조, 계산 정밀도, 채널 배치, 진단, 시험)을 정한다.
- 빌드는 순수 함수다. 패키지·Registry·프로파일을 모른다. 쿠킹(A5j)이 텍스처 객체와 프로파일 LOD 그룹에서 입력을 만들고 결과를 `TexturePlatformData`로 옮긴다.

**API**(TextureTools `TextureTools/TextureBuild.h`):
- `TextureLodGroupValues`: 빌드가 쓰는 LOD 그룹 값(12.4.5절 구현 행의 부분집합). 기본값은 UE `FTextureLODGroup` 멤버 기본값이다(TextureLODSettings.h).
  - `minLodSize` 1, `maxLodSize` 4096, `lodBias` 0, `maxLodMipCount` 32, `mipGenSettings` SimpleAverage.
  - 프로파일 표·필터·aniso·로드 옵션은 A5j가 더한다(샘플러는 빌드 결과가 아니다).
- `TextureBuildSettings`: 유효 설정이다(텍스처 값 + 그룹 값을 합친 결과 — 아래 해석 규칙).
- `ResolveTextureBuildSettings(texture, dimension, group, out) → Result<void>`: 텍스처 객체 값에서 유효 설정을 만든다. 실패는 진단과 함께 돌려준다(아래 진단).
  - 계약 설정 판정(`CheckTextureSettings`)은 Registry가 필요하므로 호출자(A5j)가 먼저 한다. 이 함수는 그룹 값의 계약 판정만 한다(그룹 `mipGenSettings`가 SimpleAverage·NoMipmaps·Unfiltered 밖이면 `UnsupportedSetting`).
- `BuildTexture(allocator, settings, sourcePixels, out) → Result<void>`: 원본 정규 픽셀(TextureSource bulk raw byte)을 쿠킹 mip으로 만든다.
- `TextureBuildResult`:
  - `pixelFormat`(GraphicsTypes `PixelFormat`), `srgb`(sRGB 형식인지), `swizzle[4]`(R·G·B·A — `TextureSwizzle`).
  - `mips`: 상위 mip부터. mip마다 `sizeX`·`sizeY`·`sizeZ`(Volume 깊이, 그 밖 1)와 byte(slice·면을 차례로 이은 형식 texel — 행 사이 패딩 없음, 위에서 아래).
  - `numSlices`(Volume 1, 그 밖 원본 slice 수).
  - `warnings`(`SrgbIgnored`·`PreserveBorderWithWrap` — 각 한 번), `failure`(code·error·detail).
- `TextureCompressionIgnoresSrgb(compression)`: 12.4.3절 SRGB 열이 "무시"인 종류인지다(Normalmap·Masks·Displacementmap·VectorDisplacementmap·HDR·Alpha·DistanceFieldFont·HDR_Compressed·HalfFloat·SingleFloat·HDR_F32).
- 새 진단 `SrgbIgnored`·`PreserveBorderWithWrap`(경고 — 4.6절 이름 그대로 `AssetDiagnosticCode`에 더한다).

**유효 설정 해석**(`ResolveTextureBuildSettings`):
- 차원은 출력 클래스의 차원이다. 원본 slice 수 규칙: Texture2D 1, TextureCube 6, TextureCubeArray 6의 배수(≥ 6), 2DArray·Volume 1 이상. 어기면 `InvalidSource`(detail = slice 수).
- `mipGenSettings` FromTextureGroup은 그룹 값이 된다. 결과는 SimpleAverage·NoMipmaps·Unfiltered 셋 중 하나다.
- `lodBias`는 텍스처 값 + 그룹 값이다. `maxTextureSize`는 텍스처 값 그대로다.
- 주소: Texture2D는 addressX·Y, 2DArray는 X·Y·Z, Volume은 addressMode(세 축), Cube·CubeArray는 Clamp다(UE TextureCube 샘플러 — 12.4.2절).
- `normalizeNormals`는 `compressionSettings`가 Normalmap일 때만 켠다(UE `bNormalizeNormals && IsNormalMap()` — TextureDerivedData.cpp).
- `powerOfTwoMode` ResizeToSpecificResolution은 Texture2D만 받는다. 그 밖 클래스는 `InvalidSetting`이다. 정규화(12.12절)가 저장 값을 None으로 바꾸므로 교환으로 들어온 값만 걸린다.

**계산 정밀도**(결정성 — 같은 입력이면 모든 호스트에서 같은 byte):
- 작업 픽셀은 float32 RGBA다. 회색 원본은 r = g = b, 알파가 없으면 1이다.
- 필터(Lanczos3)와 mip 평균은 double로 누적하고 결과를 float로 반올림해 저장한다. 곱셈과 덧셈은 별도 문장으로 써서 FMA로 합쳐지지 않게 한다.
- 초월 함수는 DeterministicMath만 쓴다: `Lanczos(x, 3)`·`SrgbToLinear`·`Gamma22ToLinear`·`LinearToSrgbByte`. CRT `pow`·`sin`은 쓰지 않는다.
- 법선 재정규화의 길이는 double `sqrt`(IEEE 정확 반올림)다.
- 16F 변환은 Core `Float16`(round-to-nearest-even — 12.2절 5번)이다.

**단계별 규칙**(12.5절 1–6번 순서):
1. 선형화(12.2절 1번):
   - `encodingOverride` Linear는 모든 정수 원본을 선형으로, sRGB는 모든 정수 원본을 sRGB 구간 함수로 읽는다.
   - None이면 8비트 원본(G8·GA8·RGBA8)은 `srgb` on일 때 `useLegacyGamma ? Gamma22ToLinear : SrgbToLinear`, off일 때 v / 255다. 16비트 원본은 v / 65535(SRGB와 무관)다.
   - float 원본은 그대로다(override도 적용하지 않는다).
   - 알파는 언제나 선형(v / 최대)이다.
2. `flipGreenChannel`: g → 1 − g.
3. `powerOfTwoMode`: slice마다(Volume은 slice의 X·Y만).
   - Pad: 늘어난 영역을 `padWithBorderColor`면 가장 가까운 테두리 texel(clamp 좌표), 아니면 `paddingColor`로 채운다. `paddingColor`는 원본과 같은 색 해석(1번)으로 디코딩한 값이고, 8비트로 보아 16비트·float 원본은 v / 255다.
   - Stretch·Resize: Lanczos3(12.5절)로 X 먼저, 그다음 Y다.
   - Resize의 대상이 0이면 그 축은 원래 길이다. Cube·CubeArray에서 결과가 정사각형이 아니면 `InvalidSetting`이다.
   - 원본 Cube 면이 정사각형이 아니면 `InvalidSource`다.
4. LOD 합성(12.5절 4번): N은 3번 결과의 1×1(×1)까지 사슬 길이다. 차원 최대는 Volume 2048(Z 포함), 그 밖 16384다.
   - NoMipmaps면 d_hard의 크기 상한만, 상위 mip이 상한 이하가 될 때까지 SimpleAverage로 한 번에 반씩 줄인다. 결과는 mip 하나다.
5. mip 생성(12.5절 5번과 mip 규칙):
   - 2DArray·Cube·CubeArray는 slice마다 X·Y만 줄인다. Volume은 Z도 줄인다(3탭 규칙이 세 축 모두).
   - PreserveBorder·NormalizeNormals는 mip 1부터 적용한다. PreserveBorder가 켜져 있고 쓰는 축 주소 중 하나가 Wrap이면 `PreserveBorderWithWrap` 경고(한 번)다.
   - 버릴 상위 mip d개도 만든 뒤 버린다(만들지 않고 건너뛰지 않는다 — 결과가 원본 mip 사슬과 같다).
6. 출력(12.4.3절 표·12.2절 3·5번):
   - 원본 종류(8비트 정수·16비트 정수·float)와 `compressionSettings`로 출력 채널 수·정밀도를 고른다.
   - 채널 배치: R 출력은 r, RG 출력은 (r, a)(GA 원본의 회색·알파 — 표 Default 행), RGBA 출력은 (r, g, b, a)다. HDR_Compressed는 데이터 알파를 1로 쓴다.
   - SRGB 판정: `srgb` on인데 `TextureCompressionIgnoresSrgb`이거나 출력이 float이면 off로 보고 `SrgbIgnored` 경고(한 번)다.
   - sRGB 출력(8비트 출력만): RGBA8은 `RGBA8UnormSrgb`다. R8·RG8은 표의 swizzle을 데이터에 먼저 적용해 RGBA8 sRGB로 넓히고 swizzle을 항등으로 둔다(D3D에 R8·RG8 sRGB가 없어 이식성을 위해 — 12.2절 3번).
   - 형식 번호: R8 `R8Unorm`, RG8 `RG8Unorm`, RGBA8 `RGBA8Unorm`·`RGBA8UnormSrgb`, R16 `R16Unorm`, RG16 `RG16Unorm`, RGBA16 `RGBA16Unorm`, R16F `R16Float`, RG16F `RG16Float`, RGBA16F `RGBA16Float`, R32F `R32Float`, RGBA32F `RGBA32Float`.
   - 양자화는 12.2절 5번이다.

**진단**(`failure` — 반환 오류와 같은 error):
- `InvalidSource`: 픽셀 byte 수가 sizeX × sizeY × slices × texel과 다름(detail = byte 수), slice 수 규칙, Cube 면 비정사각.
- `InvalidSetting`: Resize가 Cube 정사각을 깸, 비 2D Resize, 숨김 CompressionSettings(LQ·EncodedReflectionCapture).
- `UnsupportedSetting`: 그룹 mipGen이 계약 값.
- `None` + OutOfMemory: 할당 실패.

**버린 대안**:
- 작업 픽셀을 원본 채널 수대로 두기: 단계마다 채널 분기가 늘어난다. RGBA float 하나로 두고 출력에서 고른다.
- 필터를 float로 누적하기: 탭 수가 큰 축소에서 순서 오차가 커진다. double 누적 + float 저장은 결정적이고 기준값 표를 고정하기 쉽다.
- 버릴 상위 mip을 만들지 않고 원본을 바로 줄이기: 결과가 사슬과 달라진다(12.5절 5번 "만든 뒤 버린다").

**시험(A5i)**:
- mip 픽셀 표: 4×4·5×3·1×7·3×1·Volume 4×4×4·3×3×3(SimpleAverage·Unfiltered).
- PowerOfTwoMode 6종(Pad 테두리·색, Stretch 차이가 같을 때 큰 쪽, Square, Resize 0 축), Lanczos3 기준값 표(확대·축소·주소 Wrap·Mirror·Clamp, 정수 출력 자르기).
- LOD 합성 표: LODBias(텍스처 + 그룹)·MaxTextureSize·그룹 MaxLODSize·MinLODSize·MaxLODMipCount·NoMipmaps 축소·Volume 2048.
- 선형화: override 셋 × SRGB × legacy gamma × 원본 정밀도, 알파 선형, flipGreen.
- 출력: CompressionSettings 15종 × 원본 G8·GA8·RGBA8·G16·RGBA16·R16F·RGBA32F의 형식·swizzle·채널 값, sRGB 출력(RGBA8·R8·RG8 확장), SrgbIgnored, HDR_Compressed 알파 1, 양자화 경계(0.5/255·NaN·Inf·65504 넘음).
- PreserveBorder(Wrap 경고)·NormalizeNormals(Normalmap만, 길이 0).
- 진단: byte 수·slice 수·Cube 비정사각·Resize 정사각 깸·비 2D Resize·숨김 CompressionSettings·그룹 계약 mipGen, 할당 실패 전수.
- 결정성: 같은 입력 두 번 같은 byte.
