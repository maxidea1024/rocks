### 12.4 설정(UE 5.8 대조)

대조 근거: UE 5.8(5.8.4, commit `f45729c0b6f0`) 원본의 헤더 — `Engine/Source/Runtime/Engine/Classes/Engine/`의 `Texture.h`(`UTexture`·`FTextureSource`·`FTextureSourceColorSettings`), `StreamableRenderAsset.h`(기반 `UStreamableRenderAsset`의 스트리밍 멤버), `Texture2D.h`·`TextureCube.h`·`Texture2DArray.h`·`TextureCubeArray.h`·`VolumeTexture.h`, `TextureDefines.h`(관련 enum), `TextureLODSettings.h`(`FTextureLODGroup`). 처음에는 UE 5.6 공식 API 문서(C++ `UTexture` 멤버 75개, `FTextureLODGroup` 멤버 29개, Python `unreal.Texture`·`Texture2D`·`TextureCube`·`Texture2DArray`·`TextureCubeArray`·`VolumeTexture` 편집 속성 — 2026-11-12 확인)로 작성했고, 2026-11-15에 5.8 원본으로 다시 확인했다. `UTexture`·`FTextureSource`·차원별 클래스의 데이터 멤버는 5.6과 같다(추가·삭제 없음). 5.8에서 바뀐 점은 해당 행에 "5.8에서 바뀜"으로 적는다: TextureGroup 82종, `ETextureSourceEncoding`의 `HLG` 추가, `FTextureLODGroup`의 품질 등급별 상한 4개 추가(33개). 이 절의 표는 UE C++ 이름으로 적는다. Rocks 필드 이름(명령행 이름도)은 Rocks 규칙대로 camelCase이고 bool에 `b` 접두를 붙이지 않는다(`LODGroup` → `lodGroup`, `bFlipGreenChannel` → `flipGreenChannel`, `SRGB` → `srgb` — 2026-11-24 사용자 결정, 처음엔 UE 이름을 `Name="…"`로 노출했다). UE 교환은 이 대응으로 옮긴다. enum 값 이름은 UE 접두사(`TC_`·`TMGS_`·`TEXTUREGROUP_`·`TF_`·`TA_` 등)를 뗀 나머지 그대로이고 접두가 붙은 이름은 받지 않는다(예: `TC_HDR_Compressed` → `HDR_Compressed` — 2026-11-24 사용자 결정, ToolPrefix 없음). **계약** 설정은 스키마에 있고 기본값이 아니면 `UnsupportedSetting`이며, 사용자가 정한 순서(기반 → 화면 → 압축·보정·스트리밍)의 뒤 단계에서 구현한다.

#### 12.4.3 CompressionSettings → 쿠킹 형식

개정(2026-11-27, TC2): 처음 표는 UE 5.6 공개 문서만으로 정한 비압축 출력이었다. 압축 단계에서 UE 5.8 `GetDefaultTextureFormatName`(Texture.cpp 4201–4489) 원본으로 다시 정했다. 선택 순서와 조건은 12.17.5절 2번이 정본이고, 이 표는 그 요약이다. "압축"은 데스크톱 프로필(Windows·Mac)이고, 쿠킹된 상위 mip 두 변이 4의 배수이며, 비압축 강제가 아닐 때다. 비압축 강제는 compressionNone, EditorIcon, LOD 그룹 ColorLookupTable·Bokeh·IESLightProfile, Android(TC4 전)다.

- swizzle 열은 UE sampler type 계약이다(2026-11-25 렌더 세션 합의 — 12.16.4절). 셰이더가 sampler type에 따라 복제하고, 렌더러는 view swizzle을 항등으로 둔다. 형식과 무관하게 CompressionSettings로만 정한다.

- 8비트 출력의 양자화는 12.2절 5번이다. BGRA8은 B, G, R, A byte 순서이고 SRGB면 색만 sRGB로 부호화한다.

5.8에서 바뀜: `FTextureLODGroup`에 `MaxLODSize_Low`·`MaxLODSize_Medium`·`MaxLODSize_High`·`MaxLODSize_Epic`(`r.TextureGroup.QualityLevel`·`r.TextureGroup.MaxQualityLevel` 품질 등급별 상한, 가상 텍스처에는 쓰지 않음)이 더해져 멤버가 33개가 되었고(TextureLODSettings.h 76–90), `UTextureLODSettings`에 쿠킹 때 `OptionalMaxLODSize` 대신 품질 등급 상한을 쓰게 하는 `TextureGroupOptionalQualityLevel`이 더해졌다(263–265). 위 표는 5.6의 29개 기준이다. 새 멤버 넷은 계약이다(12.14절 칸 `maxLodSizeLow`…`Epic` — 저장·전달만, `!GIsEditor` 런타임 값, TextureLODSettings.cpp 97–105).

**메시 LOD 그룹**(메시 에셋 스펙 MR9, 2026-11-20). 메시도 텍스처처럼 그룹 이름(`lodGroup`)으로 TargetProfile의 기본값을 받는다([MeshAnimationAssets](../../MeshAnimationAssets/04-CommonSettings.ko.md) 4.7절). TargetProfile에 텍스처 LOD 그룹 표와 나란히 메시 LOD 그룹 표를 둔다. 항목은 UE 5.8 `FStaticMeshLODGroup`(Engine/Public/StaticMeshResources.h:58)의 멤버에 대응한다: 기본 LOD 수(`DefaultNumLODs`), 스트리밍·선택 LOD 수 상한(`DefaultMaxNumStreamedLODs`·`DefaultMaxNumOptionalLODs`), LOD 스트리밍 지원(`bSupportLODStreaming`), 기본 라이트맵 해상도(`DefaultLightMapResolution`), LOD별 기본 축소 설정(`DefaultSettings[]`)과 축소 설정 보정(`SettingsBias`·`BasePercentTrianglesMult`·`BasePercentVerticesMult`). 화면 크기·최소 LOD는 그룹이 아니라 메시 에셋의 플랫폼별 값이다(텍스처와 같은 덮어쓰기 표). 축소 관련 항목은 축소기가 생길 때까지 보존 상태다(MeshAnimationAssets 4.2절).
