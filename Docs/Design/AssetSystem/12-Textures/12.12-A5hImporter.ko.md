### 12.12 A5h 구현 명세 — 텍스처 임포터(2026-11-24, 착수 전)

12.3절 원본 구성과 13절 명령 문법을 A2f 임포트 프레임워크(7.1절 18·19)로 구현한다(12.7절 A5h). 원본 디코딩은 ImageCodec(12.9–12.11절), 저장 설정 규칙은 12.2절 4번·12.10절 encoding이다. 새 임포트의 설정 기본값은 UE 5.8 `UTextureFactory`·`ApplyDefaultsForNewlyImportedTextures`·`SetModernSettingsForNewOrChangedTexture`와 같게 한다(애매하면 UE).

**모듈** `TextureTools`(Engine/Source/Developer/TextureTools — 공개 의존 Core·Texture·AssetDatabase, 비공개 ImageCodec·AssetRuntime). 임포터 9개를 두고 `RegisterTextureImporters(state, table, tokens)`(7.1절 18 `AssetImporterSetup` 형식)로 등록한다. Commandlet 제품 호스트가 이 함수를 `AssetCommandContext::importers`에 건다. 빌드(A5i)·쿠킹(A5j)도 이 모듈에 더해진다.

**임포터**(이름 = `--importer=`·기록 importerName, 주 출력 클래스, 원본 역할):

| 임포터 | 출력 | 원본 역할 | 옵션 | 기본 확장자 |
|---|---|---|---|---|
| `texture` | Texture2D | `source` | `pngInfill` | png bmp tga icb vda vst psd dds tif tiff hdr exr jpg jpeg webp |
| `texture_cube` | TextureCube | `px` `nx` `py` `ny` `pz` `nz`(고정 6) | `pngInfill` | — |
| `texture_cube_file` | TextureCube | `source` | `cubeLayout`·`pngInfill` | — |
| `texture_array` | Texture2DArray | `slice:<i>`(가변만) | `pngInfill` | — |
| `texture_array_file` | Texture2DArray | `source`(DDS 2DArray) | — | — |
| `texture_cube_array` | TextureCubeArray | `cube:<i>.<면>`(가변만) | `pngInfill` | — |
| `texture_cube_array_file` | TextureCubeArray | `source`(DDS CubeArray) | — | — |
| `texture_volume` | VolumeTexture | `slice:<i>`(가변만) | `pngInfill` | — |
| `texture_volume_file` | VolumeTexture | `source` | `volumeTileX`·`volumeTileY`·`pngInfill` | — |

- 역할 이름 개정(5.4절 원본 역할 — 처음 이름 `0`·`<i>.<면>`은 A2f3b 가변 역할 규칙(접두 + 비지 않은 뒤)으로 쓸 수 없었다): 2DArray·Volume slice `slice:<i>`, CubeArray `cube:<i>.<면>`(`<i>`는 0부터 10진, 앞 0 없음). Cube 면 `px`…`nz`와 2D `source`는 그대로다.
- **가변만 받는 임포터**(A2f 프레임워크 보강 — 7.1절 18 개정): `AssetImporterInfo::variableSourcesOnly`(bool, 기본 false). 참이면 `roles`가 비어야 하고 `rolePrefixes`는 하나 이상이며(아니면 등록 `InvalidArgument`), 고정 역할(기본 `source` 포함)이 없고 원본은 가변 역할 하나 이상이다(0개는 `InvalidImportOption`). 서비스의 역할 정렬(`OrderImportRoles`)·단일 원본 재지정(`--source=` — 가변만 받는 임포터는 받지 않는다, 사용법 오류)이 이 표지를 본다.
- 가변 역할은 프레임워크가 byte 순으로 준다(`slice:10`이 `slice:2` 앞) — 임포터가 번호를 수로 풀어 0부터 빈틈 없는지 본다(아니면 `InvalidImportOption`, detail = 원본 번호). CubeArray는 cube마다 면 6개가 모두 있어야 한다.
- 옵션 struct(`ROCKS_STRUCT` — 필드 이름은 텍스처 속성 이름·13절 예약 이름과 겹치지 않는다): `TextureImportOptions{pngInfill}`, `TextureCubeFileOptions{cubeLayout, pngInfill}`, `TextureVolumeFileOptions{volumeTileX, volumeTileY, pngInfill}`. `TextureImportPngInfill`(enum — UE `ETextureImportPNGInfill`: `OnlyOnBinaryTransparency` 기본·`Always`·`Never`), `TextureCubeLayout`(enum `None`·`HorizontalCross`·`VerticalCross`·`Strip6`, 기본 None). 옵션은 ImportRecord에 남는다(재임포트가 같은 옵션을 쓴다 — 5.4절 옵션 경계).

**구성 규칙**(원본마다 `DecodeImage` — 원본 경로 힌트를 넘긴다):
- 디코딩 실패는 `context.Fail(디코더 진단 코드, 오류, detail = 원본 번호)`다(한도는 디코더 기본 `ImageDecodeLimits`). 디코더 경고는 `context.Warn(코드, detail = (원본 번호 << 32) | 디코더 detail)`이다.
- `texture`: 결과가 Texture2D 차원이어야 한다. DDS Cube·배열·Volume은 `InvalidImportOption`(detail = 결과 차원 값 — 명령은 `--importer=texture_cube_file` 등을 쓴다. UE는 DDS의 차원으로 클래스를 고른다 — Rocks는 임포터마다 출력 클래스가 하나라 명시한다, UE와 다르다).
- 여러 원본(`texture_cube`·`texture_array`·`texture_cube_array`·`texture_volume`): 원본마다 Texture2D 한 장이어야 하고 모두 같은 크기·같은 `TextureSourceFormat`이어야 한다(아니면 `InvalidImportOption`, detail = 처음 다른 원본 번호 — 형식 변환은 하지 않는다). Cube 면은 정사각형이다. slice 순서: Cube +X −X +Y −Y +Z −Z, 2DArray·Volume 번호 순, CubeArray cube 번호 순 × 면 순.
- `texture_cube_file`: `cubeLayout`이 None이면 결과가 DDS Cube(차원 TextureCube)여야 한다. 배치면 결과가 Texture2D이고 크기가 배치 칸(HorizontalCross 4×3, VerticalCross 3×4, Strip6 6×1)으로 나뉘고 칸이 정사각형이어야 한다(아니면 `InvalidImportOption`). 칸 배치는 12.3절 표(VerticalCross의 −Z는 180° 돌려 담긴 것을 되돌린다).
- `texture_volume_file`: 타일이 0×0이면 결과가 DDS Volume이어야 한다. 아니면 결과가 Texture2D이고 크기가 타일로 나뉘어야 하며(slice 수 = 열 × 행 ≤ `maxSlices`) slice 순서는 왼쪽 → 오른쪽, 위 → 아래다(UE `UVolumeTexture::UpdateSourceFromSourceTexture`와 같다 — 구현 때 대조).
- `*_array_file`·`*_cube_array_file`: 결과 차원이 그 클래스와 같아야 한다.

**원본 저장**: `TextureSource{format, sizeX, sizeY, numSlices, numMips = 1, numLayers = 1, bulk}`. bulk는 `context.AddBulk`(정규 픽셀 — slice를 차례로 이은 byte). 에디터 패키지 저장의 bulk codec을 Zstd로 바꾼다(5절 개정 — 지금은 None이다. UE `FEditorBulkData`도 원본을 압축한다). 이는 텍스처만이 아니라 모든 에디터 bulk에 적용된다(시험 golden은 빌드 때 다시 만든다).

**새 임포트 기본값**(재임포트는 사용자 설정을 그대로 둔다 — UE `bUsingExistingSettings`):
1. UE `SetModernSettingsForNewOrChangedTexture`: `compositeTextureMode` = Disabled(합성 텍스처가 없으면), `doScaleMipsForAlphaCoverage`가 꺼져 있고 `alphaCoverageThresholds`가 0이면 (0, 0, 0, 0.75), `normalizeNormals` = true, `useNewMipFilter` = true.
2. 회색 자동 감지(UE `AutoDetectAndChangeGrayScale` — 늘 한다): RGBA8 결과의 모든 texel이 R = G = B이고 A = 255면 G8로 바꾼다.
3. PNG infill(UE `FillZeroAlphaPNGData` — PNG만, 옵션 `pngInfill`): `OnlyOnBinaryTransparency`면 알파가 0·최대뿐이고 알파 0 texel이 흰색(RGB 최대)일 때, `Always`면 알파 0 흰색 texel이 있을 때 그 RGB를 이웃 색으로 채운다(UE와 같은 반지름·가중치·행 채우기). 가중치 `exp(−1.1·√(r²))`는 미리 계산한 상수 표로 둔다(호스트 libm 차이 없이 결정적 — UE `expf` 값과 같게 맞춘다, 빌드 때 대조).
4. float 결과(R16F·RGBA16F·R32F·RGBA32F)는 `compressionSettings` = HDR(UE)이고, 이어 UE 기본 설정 `CompressedFormatForFloatTextures = HDRCompressed_BC6`(BaseEditor.ini)를 따라 `HDR_Compressed`다.
5. TGA 형식 1(색표)·형식 3(회색)의 8비트는 `compressionSettings` = Grayscale이고 형식 3은 SRGB를 끈다(UE EditorFactories.cpp 3050–3083). — 형식 1은 Rocks가 색표를 적용해 RGBA8로 푼다(12.9절 — UE와 다르다): 색표가 회색이면 2번이 G8로 바꾼다.
6. SRGB = UE `GetDefaultSRGB(compressionSettings, 형식, encoding != Linear)`(12.10절 — Default·EditorIcon의 8비트는 encoding대로(Unknown은 Srgb로 본다), 16비트 정수는 on, 그 밖 종류는 off).
7. 2의 거듭제곱이 아닌 Texture2D(UE `bDoAutomaticTextureSettingsForNonPow2Textures` 기본 true): `mipGenSettings`가 FromTextureGroup이면 NoMipmaps, 크기가 4의 배수가 아니고 `compressionSettings`가 Default면 EditorIcon.
8. 받지 않는 UE 기본값: 큰 텍스처의 가상 텍스처 자동 켜기(UE `AutoVTSize` 4096 — 가상 텍스처는 계약, 12.4절), 원본 mip 보존(LeaveExistingMips — 계약, 12.10절), 법선 맵 자동 감지(UE `NormalMapIdentification::HandleAssetPostImport` — 화소 통계 휴리스틱, 보정 단계에서 후속).

**재임포트**(UE `ApplyDefaultsForNewlyImportedTextures(bIsReimport)`): 설정은 그대로 두고 원본만 바꾼다. 다만 Texture2D가 NoMipmaps·Default 또는 EditorIcon·UI 그룹이 아닌데 새 원본이 2의 거듭제곱이면(`powerOfTwoMode`가 None이 아니어도) `mipGenSettings` = FromTextureGroup, `compressionSettings` = Default, `neverStream` = false로 되돌린다(UE와 같다).

**설정 보정 hook**(12.2절 4번 — `asset-import`·`asset-reimport`·`asset-set` 공통): AssetRuntime `AssetTypeHooks`에 새 hook `AssetSettingsFixupHook(context, object, assignedFields)`를 둔다 — 서비스가 명령의 설정 대입(옵션이 아닌 것)을 적용한 뒤, 검증 전에 부른다(`assignedFields` = 대입한 최상위 필드 이름). Texture hook: `compressionSettings`를 대입했고 `srgb`를 대입하지 않았으며 그 종류가 SRGB를 무시하는 종류(12.4.3절 표의 "무시" — 새 공개 함수 `TextureCompressionIgnoresSrgb`, A5i도 쓴다)면 `srgb` = 0. 새 임포트는 4–6번 기본값 뒤에 사용자 대입이 오고 그 뒤 hook이 돈다(사용자가 준 값이 이긴다).

**명령 문법**(13절 — 예약 이름을 임포터·역할·옵션으로 옮긴다, `--importer=`와 함께 쓰면 사용법 오류):

| 명령 | 임포터 | 원본·옵션 |
|---|---|---|
| `<path> <file>` | 확장자 기본(`texture`) | `source` |
| `<path> <file> --cube-layout=<배치>` | `texture_cube_file` | `source`, `cubeLayout=<배치>` |
| `<path> <file> --volume-tile=<W>x<H>` | `texture_volume_file` | `source`, `volumeTileX=W`, `volumeTileY=H` |
| `<path> --cube=px:<f>,nx:<f>,…` | `texture_cube` | 면 6개(순서 자유, 같은 면 둘·빠진 면은 사용법 오류) |
| `<path> --array=<f>,<f>,…` | `texture_array` | `slice:0`… |
| `<path> "--cube-array=<cube 지정>;<cube 지정>"` | `texture_cube_array` | `cube:<i>.<면>` |
| `<path> --volume=<f>,…` | `texture_volume` | `slice:0`… |

DDS Cube·배열·Volume 한 파일은 `--importer=texture_cube_file`·`texture_array_file`·`texture_cube_array_file`·`texture_volume_file`로 고른다. 목록·이스케이프 규칙은 13절 그대로다. 해석은 AssetCommandlets의 임포트 인자 읽기가 하고, 같은 표를 TextureTools의 `TextureImportSpec`(서비스 API 구조 — 차원·원본 목록·배치·타일·infill)과 `MakeTextureImportRequest(spec) → (임포터 이름, 원본 역할 목록, 옵션 대입)`이 에디터·도구에 준다(명령 해석과 같은 함수를 쓴다).

**버린 대안**: 임포터 하나가 결과 차원으로 클래스를 고르기(UE 방식 — A2f는 임포터마다 출력 클래스가 하나다, 프레임워크를 바꾸면 설정 대입 대상이 원본에 따라 달라진다), 고정 역할 `source` + 가변 역할로 slice를 받기(첫 slice만 다른 이름이 된다 — 프레임워크 표지 하나로 푼다), 원본마다 다른 형식을 넓혀 합치기(첫 판은 엄격 — 필요하면 후속), 에디터 bulk 압축을 텍스처만(bulk codec이 패키지 단위다 — 모든 에디터 bulk를 압축해도 해가 없다).

**시험(A5h)**: 프레임워크 표지(등록 규칙·역할 0개·번호 정렬·`--source=` 거부), 임포터 9개의 성공 경로(시험 생성기 PNG·DDS 원본 — 크기·형식·slice 순서·bulk 내용), 구성 위반 각각(크기·형식·정사각·배치 나눔·타일 나눔·번호 빈틈·면 빠짐·차원 불일치), 기본값 1–7번 각각과 재임포트 보존·되돌림 규칙, 회색 자동 감지·PNG infill 세 값(UE 결과와 같은 화소 — 작은 그림의 기대 표), SRGB 표(종류 × 형식 × encoding), 설정 보정 hook(asset-set·import에서 srgb 대입 있음·없음), 명령 문법 표 전부와 사용법 오류, 경고 detail 합성, 디코딩 실패 detail, 에디터 bulk Zstd 저장·읽기, 할당 실패.
