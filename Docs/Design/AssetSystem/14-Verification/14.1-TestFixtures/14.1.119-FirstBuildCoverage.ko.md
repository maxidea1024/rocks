사유와 후속(우선순위 순 — 다음 묶음에서 시험을 더하고 이 표를 고친다):

1. 할당 실패(alloc 367줄): NFail 전수 시험이 없는 경로다. `TextureCook_AllocationFailures`(이번에 더함 — 쿠킹 문맥 Allocator, 너겟 미적중·적중)와 같은 방식으로 `TextureSourceRebuild`(hook·sink·전파 — 14.1.103 빌드 때 항목), `TextureImportRequest`·`TextureImporter`, `EncodeTiff`·`EncodeExr`, 명령(`AssetCookCommandlet`·`AssetLoadCookedCommandlet`·`NuggetGcCommandlet`·`ClassDefaultsCommandlet` — 시험 문맥 Allocator)에 더한다.
   - 진행(2026-11-25): `TextureSourceRebuild_AllocationFailures`(객체 Registry·sink 할당 — 2DArray 잇기·변환, CubeArray, 전파, Volume 기본 타일·빈 원본 경고·asset-new 기본 원본; 시도마다 새 장면), `TextureImport_AllocationFailures`(PNG 투명·회색, Cube 6면, 한 파일 Cube·Volume, Array, 재임포트), `TiffEncode_AllocationFailures`(LZW·Deflate tile·JPEG·색표·여러 page BigTIFF — 누수 세기), `ExrEncode_AllocationFailures`(Zip·Piz tile mip·part 둘 RLE — 누수 세기)를 더했다. 시험이 찾은 결함 셋: EncodeTiff·EncodeExr가 Rocks 쪽 할당(출력·줄·tile·0 버퍼) 실패를 `InvalidArgument`로 냄(12.10.1절), libtiff `_TIFFVSetField` 배열 복사 실패 뒤 null 배열 태그(접근 위반), OpenEXRCore `internal_exr_revert_add_part` part 구조체 누수(12.10절 Rocks.patch). 시험 문맥 Allocator: TextureEnv의 객체 Registry가 `objectAllocator`(NFail — 평소는 그대로)를 거친다. 남은 것: `TextureImportRequest`, 명령 넷. 표 수치는 다음 측정 때 고친다.
   - 진행(2026-11-26): `TextureImport_TranslateAllocationFailures`(Cube 이스케이프·Array·CubeArray·Volume·한 파일 Cube·Volume 타일·사용법 위반 — 번역 작업·결과 Allocator)와 `AssetCommands_AllocationFailures`(asset-cook `--verify-nuggets` 전체 쿠킹·전부 재사용, asset-load-cooked, nugget-gc, class-defaults-dump — 시험 문맥 Allocator, 같은 프로젝트에서 이어 부름)를 더했다. 시험이 찾은 결함 여섯: `TextureImportRequest`의 목록 나누기(`SplitRaw`)가 할당 실패를 사용법 위반(거짓)으로 냄, `OpenProject`(에셋 명령 공용)가 경로·프로젝트 찾기 할당 실패를 진단 줄로 냄, class-defaults-dump가 타입 모듈 시작 할당 실패를 진단 줄로 냄, `NuggetFileSystemBackend` 생성자가 root 복사 실패를 버려 `Open`이 `InvalidArgument`(빈 루트)로 냄, 로더가 할당 실패로 끝난 단위에 기대는 요청을 `DependencyFailed`/`MissingDependency`로 냄(11.6절 6번 개정), `ObjectRegistry` STW `Collect`가 root 없이도 작업 큐를 확보해 파괴자의 `Shutdown`이 할당 실패로 Busy → Fatal(Docs/Implementation/FoundationStatus 7번 개정 — root가 없으면 확보하지 않는다). 이로써 1번의 남은 경로(번역·명령 넷)를 다 더했다.
2. 출력 실패(output 192줄): 명령 출력 스트림 실패(`CommandletOutput` 실패 주입 — `AssetCookCommand_OutputFailures`가 cook 일부만 본다)와 TextureCook·TextureSourceRebuild의 진단 기록 실패(sink 실패)다. 출력 실패 주입 시험을 명령마다 더한다.
3. 손상 입력(other — ImageCodec 디코더 약 400줄): BMP·PNG·PSD·TGA·TIFF·DDS·EXR의 형식 위반 갈래 대부분이 시험 생성기에 없는 변형이다(14.1.91·14.1.93의 빌드 때 항목: PngSuite, 외부 참조 파일, BMP RLE4·delta, TGA 15·16비트 등). 외부 참조 파일 대조와 무작위 변조(fuzz — AssetPackage처럼 고정 seed)로 덮는다.
4. ClassDefaults·Changed·Revert(other 약 150줄): A5a·A5b2 빌드 때 항목(배열·Set·Map 재생, ClassRef 재판정, 할당 실패 주입 fixture)이다.
5. 방어 검사(other 나머지): 호출자가 이미 막는 값의 재검사·도달하지 않는 switch 기본 갈래다. 다음 묶음에서 파일마다 줄을 확인해 사유를 이 절에 적는다(남김 사유) — 그 전에는 위 1–4가 덮는 만큼을 먼저 줄인다.
