#### 14.1.117 요구 대조표(A5j2b — 텍스처 원본 묶음의 UE 변환 경로)

명세는 [12.14절 A5j2b](../../12-Textures/12.14-A5jCook.ko.md)이고, A5i 풀기 수정은 12.13절이다.

구현:
- TextureTools 새 공개 헤더 `TextureSourceConvert.h`:
  - `CommonTextureSourceFormat`: UE `GetCommonSourceFormat`을 Rocks 원본 형식으로 옮긴 그래프.
  - `TextureSourceGamma`(Linear·Srgb·Pow22).
  - `ConvertTextureSource`: 같으면 byte 그대로, 같은 감마의 넓히는 변환은 직접 경로, 그 밖은 RGBA32F 선형을 거치는 두 단계, 그 뒤 재표본.
- 내부 헤더 `TextureBuildInternal.h`: 빌드와 변환이 같이 쓰는 `Level`·`DecodeTexels`·`ResampleLevel`·양자화·작업 메모리 상한.
- A5i 수정: `DecodeSource`를 핵심 `DecodeFormat`으로 나누고, R16F·R32F를 (v, 0, 0, 1)로 고쳤다(UE `CopyImage`).
- `TextureSourceRebuild`: 원소 감마를 셋(sRGB·Pow22·선형)으로 본다.
  - UE 순서로 접는다(감마가 갈리면 RGBA32F 선형, 그다음 공통 형식). 2DArray 크기는 최대 X·Y로 정한다.
  - 원소의 형식·크기가 같으면 byte 그대로, 다르면 `ConvertTextureSource`로 바꾼다.
  - CubeArray는 크기가 다르면 거부한다.

| 요구 | 항목 | 시험 |
|---|---|---|
| 공통 형식 | 10 × 10 모든 쌍과 교환 대칭, Invalid | `TextureSourceConvert_CommonFormatTable` |
| 직접 경로 | G8 sRGB → RGBA8 sRGB 256값 복제, 선형 G8 → RGBA16 v·257, GA8 → RGBA8 (L, L, L, A), G16 → GA16 (v, 65535) | `TextureSourceConvert_DirectPaths` |
| 풀기·좁히기 | R32F → RGBA32F (v, 0, 0, 1), RGBA32F → G8 sRGB는 R만(0·188·255), half RTNE·+Inf | `TextureSourceConvert_DecodeAndNarrowing` |
| 재표본 | 균일 G8 확대·축소, RGBA8 sRGB 색·선형 알파 유지, 같은 크기는 byte 그대로 | `TextureSourceConvert_Resample` |
| 오류·할당 | byte 수·크기 0·대상 Pow22·16비트 sRGB·Invalid → InvalidArgument, 작업 메모리 상한 → CapacityExceeded(읽기 전), 할당 실패 전 지점 | `TextureSourceConvert_ErrorsAndAllocations` |
| 배열 변환 | G8 + RGBA8 → RGBA8(복제·byte 그대로), sRGB + Pow22 → RGBA32F 선형, Pow22 + 선형 같은 형식은 byte 그대로, G16 선형 + RGBA8 sRGB → RGBA32F, R16F + RGBA16F의 (v, 0, 0, 1), 크기가 다른 2DArray는 최대 X·Y, CubeArray는 형식이 달라도 받고 크기가 다르면 InvalidSetting | `TextureSourceRebuild_ArrayConversion` |
| 남은 거부 | null·원본 없음·numLayers·numMips·byte 한도·임포트한 배열 | `TextureSourceRebuild_ArrayChecks` |

빌드 때 더할 것(화면 마일스톤 뒤 — 미빌드):
- 시험 실행.
- UE 대조 golden: 같은 원소 셋을 UE에서 묶은 결과다. 재표본하지 않은 원소는 byte 일치, 재표본한 원소는 ±1 LSB다. GA8은 BGRA8 (L, L, L, A)로 대응한다.
- A5i 빌드에서 R16F·R32F 원본으로 RG·RGBA를 출력하는 경우 G·B 값을 대조한다.
- coverage 사유.
