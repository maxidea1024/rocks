#### 14.1.125 요구 대조표(PR12c — 스트리밍 bulk 범위 읽기)

명세는 [20.6절](../../20-StreamingBulk.ko.md)이다.

구현:
- `AssetRuntime/StreamedBulk.h`: 범위 IO 경계 `StreamedBulkIo`(Open·Read·Cancel·Release·Close)와 기본 구현 `AsyncStreamedBulkIo`, `StreamedBulk`·`BulkReadHandle`·`BulkReadPriority`·`BulkReadState`·`BulkReadResult`.
- `AssetManager::OpenStreamedBulk(lease, ref)`, `AssetManagerConfig::streamedIo`·`streamedMaxInFlight`(기본 8). Package가 sidecar 상태(`Package::Sidecar()`·`BulkSlot`)를 쥔다.
- 내부 `StreamedBulkSystem`(뮤텍스 하나): 경로별 계수 파일 기록, 우선순위 큐, 진행 상한, worker 열기·검증·끝내기 작업, 블록 경계 scratch 읽기와 블록 SHA-256 검증.
  - IO 취소는 핀(`ioPins`)을 올린 뒤 뮤텍스 밖에서 보낸다. 검증 작업은 핀이 0이 될 때까지 Release를 미룬다.
  - Shutdown은 큐를 먼저 끝내고, 진행 IO를 하나씩 취소한 뒤 `outstanding`을 조건 변수로 기다린다.
- EngineAssets가 자기 AsyncIoContext로 `AsyncStreamedBulkIo`를 만들어 넘긴다.
- `AssetLoaderWorker::Run` 계약을 "아무 스레드"로 넓혔다.
- 시험 보조 `WriteWholeFile`·`MakeParent`를 `LoaderTestSupport.h` 하나로 모았다(세 복사본 제거).

| 요구 | 항목 | 시험 |
|---|---|---|
| 범위 경계 | 0·1 byte·블록 경계 넘음·끝·전체·0 byte Done과 byte, IO 시작은 블록 배수, 같은 파일 한 번 열기, 다른 sidecar 따로 열기, callback worker 한 번 | `StreamedBulk_ReadsAndVerifies` |
| 거부 | 패키지 안 bulk Unsupported, 빈 ref InvalidArgument, 없는 bulkId NotFound, 다른 값 TypeMismatch, 빈 lease StaleHandle, IO 없음 Unsupported, Read 빈 StreamedBulk·null callback·끝·offset 넘침 | `StreamedBulk_Rejections` |
| 손상·IO 오류 | 블록 1 byte만 바뀜 → 그 블록 읽기만 CorruptData, 짧은 읽기, 읽기 IO 오류, 즉시 제출 실패, 크기 다름·머리 손상·없음·열기 오류가 파일에 남음 | `StreamedBulk_CorruptionAndIoErrors` |
| 큐·취소 | 진행 상한 1에서 우선순위 순·승격·제출 전 취소, 제출 뒤 취소(Cancelled·경합 Done), 진행 상한 4 완료 재정렬 | `StreamedBulk_QueueOrderAndCancel` |
| 취소 경합 | io.Read 안에서 온 취소가 Read 뒤 IO 취소 한 번 → Cancelled, 완료 뒤·검증 전 취소는 Done·IO 자원 반환 | `StreamedBulk_CancelRaces` |
| 수명 | callback 안 자기 손잡이 파괴, lease 반납 뒤 읽기, 손잡이가 StreamedBulk보다 오래 삶, 마지막 해제 뒤 파일 한 번 닫힘 | `StreamedBulk_LifetimeRules` |
| 종료 | 큐 Cancelled, 진행 IO 취소(도우미 스레드 gate), 뒤 Open·Read ShuttingDown, 진행 IO 둘 중 이미 취소된 것은 건너뜀 | `StreamedBulk_Shutdown` |
| 할당 실패 | OpenStreamedBulk·Read·검증 모든 지점 OutOfMemory, 다 지나면 Done | `StreamedBulk_AllocationFailures` |
| worker 제출 실패 | 열기 예약 실패 → 파일 실패(IO 열기 없음)·그 자리 callback, 0 byte 그 자리 Done, 다시 열면 새로 엶, 검증 예약 실패 → 그 오류·IO 자원 반환, IO 오류가 먼저면 그 오류 | `StreamedBulk_WorkerRunFailures` |
| lease·스레드 | scope Revoke 뒤 읽기, 회수 lease StaleHandle, 다른 스레드 WrongThread, 진행 상한 0 InvalidArgument | `StreamedBulk_LeaseAndThreadRules` |
| 디스크 IO | 실제 `AsyncStreamedBulkIo`·`WorkerSchedulerLoaderWorker`로 전체·블록 경계 읽기, 4 스레드 동시 읽기(시작 gate), `AsyncIoFaultPoint::Completion` 오류, 블록 손상 sidecar, 읽기를 건 채 Shutdown(Done 또는 Cancelled) | `StreamedBulk_DiskIo` |
| 수명 위반 | Pending 손잡이 소멸, 살아 있는 StreamedBulk를 남긴 파괴가 Fatal(자식 프로세스) | `StreamedBulk_LifetimeViolationsAreFatal` |

남은 것: 4 GiB 상한은 그만한 sidecar가 필요해 시험하지 않는다(검사는 읽기와 같은 넓힌 범위 계산을 쓴다).
