#### 14.1.113 요구 대조표(A4f4 — 엔진 전용 쿠킹·쿠킹 루트 잠금)

명세는 [10.3절 7항](../../10-Cooker/10.3-ShaderLibrary.ko.md)과 [10.3.1절 A4f4](../../10-Cooker/10.3.1-A4fDetails.ko.md), 11.8절(쿠킹 루트 기본값)이다.

구현:
- AssetCooker:
  - `CookRootLock`(`<Saved>/Locks/Cooked-<Profile>.lock`, FileLock, `IsHeldFor` SHA 대조).
  - `CookPublishConfig::savedDirectory`(layout 대신)·`Begin(const CookRootLock&)`·`AppendCookedRoot(out, saved, profile)`.
  - `CookProjectRequest::cookLock` — 두 잠금 확인.
  - `CookEngineRequest`·`CookEngine`. 단계·보고서·기존 매니페스트 읽기는 `CookProject`와 공용 내부 함수다(`RunArtifactStages`·`WriteReport`·`ReadPreviousManifest`).
  - `CookArtifactRequest::nuggets` null의 뜻을 주석에 적었다.
- AssetCommandlets:
  - `asset-cook --engine`: 프로젝트 세션 없이 타입·쿠커 모듈, 자기 ObjectRegistry, 엔진 프로필, 엔진 CookSettings.
  - 두 잠금의 `--wait` 마감 시각 하나(`RemainingWaitMilliseconds`).
  - 쿠킹 루트 잠금 Busy 줄, 결과 출력 공용 `WriteCookOutcome`(색인 없는 진단 대상).
  - `AssetCommandContext::engineDirectory`.
- EngineAssets: `SetEngineOnlyDirectory`, `ResolveCookedRoot(configured, engineOnly, profile, executableDir, out)`, Initialize가 프로파일을 먼저 정한다.
- Sandbox 호출은 Sandbox가 EngineAssets를 붙일 때다(10.3.1절 A4f4 5번 — 지금 의존 없음).

| 요구 | 항목 | 시험 |
|---|---|---|
| 잠금 | 잡기·잠금 파일 위치, 이미 쥠 AlreadyExists, 같은 루트 두 번째 Busy, 다른 프로필 독립, `IsHeldFor`(다른 프로필·다른 Saved·빈 인자·놓은 뒤 거짓), 놓은 뒤 다시, 빈 인자 InvalidArgument, 경로 조립 할당 실패 | `CookRootLock_AcquireAndRelease` |
| 게시기 | 빈 savedDirectory·잠금 없음·다른 프로필 잠금 InvalidArgument, 기존 게시 시험은 쿠킹 루트 잠금으로 | `CookPublish_RejectsAndFaults`·`CookPublish_*` |
| CookProject 잠금 | cookLock null·없음·다른 쿠킹 루트, 쿠킹 루트만 쥐고 에셋 DB 잠금 없음 → InvalidArgument | `CookProject_CorruptManifestAndRejects` |
| CookEngine | Engine만(형식 둘)·entryCount 0·engineOnly 요청·파일 대조·보고서, 재쿠킹 재사용·새 byte 0, verify 전달·후보 없음, 깨진 이전 매니페스트 경고 뒤 전체 쿠킹, 미등록 UnsupportedCapability, 셰이더 없는 프로필 빈 매니페스트·단계 안 부름 | `CookEngine_PublishesEngineLibraries` |
| 계약·거부 | Project Produce → InvalidArgument·stageFailure Produce(D3D12_SM6)·게시 안 함, 인자 null·빈 savedDirectory·잠금 없음·다른 루트 잠금 | `CookEngine_ContractAndRejects` |
| 할당 | 첫 엔진 쿠킹·재사용 쿠킹의 모든 지점 OutOfMemory, 표 사용 중 아님 | `CookEngine_AllocationFailures` |
| 명령 사용법 | `--engine`과 `--project`·경로·`--verify-nuggets-source`, `--engine` 두 번, 프로필 없음 → 2 | `AssetCookCommand_Usage` |
| `--wait` | 마감 시각 하나: 남은 밀리초·다 씀 0·시계 거꾸로 | `AssetCookCommand_RemainingWait` |
| 명령 잠금 | 쿠킹 루트를 다른 쪽이 쥐면 프로젝트 쿠킹 Busy 줄, 놓으면 됨 | `AssetCookCommand_CookRootLock` |
| 명령 엔진 전용 | 임시 엔진 디렉터리(문맥 재정의)에 게시·targets 0·프로젝트 쿠킹 루트 안 건드림, 엔진 CookSettings 문법 오류 줄, 잠금 Busy, `--json`의 Engine 항목 | `AssetCookCommand_EngineCook` |
| 쿠킹 루트 기본값 | 설정 값 우선, 엔진 전용 디렉터리 `<엔진>/Saved/Cooked/<프로파일>`(프로파일 빔 InvalidArgument), 그 밖 실행 파일 기준, 할당 실패 | `EngineAssets_ResolveCookedRoot` |

빌드 때 더할 것(화면 마일스톤 뒤 — 미빌드): 시험 실행, `SetEngineOnlyDirectory`가 Initialize의 쿠킹 루트를 바꾸는 엔진 시험(디스크 장면 루트를 엔진 쿠킹 루트 모양으로 두는 픽스처), coverage 사유.
