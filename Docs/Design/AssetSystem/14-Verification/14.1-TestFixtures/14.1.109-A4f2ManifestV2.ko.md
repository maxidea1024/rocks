#### 14.1.109 요구 대조표(A4f2 — 쿠킹 매니페스트 v2: backend 표·artifact 표)

명세는 [10.3절 4·8항](../../10-Cooker.ko.md)과 10.3.1절 A4f2다. v1 대조표 [14.1.3](14.1.1-A1FormatManifestLoader.ko.md)의 행은 그대로 v2 배치로 돈다. 이 표는 v2에서 더한 것만 적는다.

구현:
- AssetRuntime `CookedManifest.h`/`.cpp`:
  - 형식 버전 2.
  - 모델: `CookArtifactKind`·`CookedManifestBackend`·`CookedManifestArtifact`, `CookedManifest::backends`·`artifacts`·`Backends()`·`Artifacts()`·`FindArtifact`.
  - 함수: `CookedArtifactLess`·`AppendCookedArtifactPath`·`CheckCookedArtifactFile`.
  - 어휘·문법 `IsKnownGraphicsBackend`·`IsValidShaderFormatId`·`ShaderFormatIdMaxBytes`를 TargetProfiles에서 옮김.
  - 진단 칸 12개(`ArtifactCookKey` 포함), 상한 `CookedManifestMaxArtifacts`·`CookedArtifactMaxBytes`.
- TargetProfiles `MakeCookedManifestBackends`.
- AssetCooker: `CookPublishConfig::backends`, `Finish`가 backend 표를 복사하고 부분 쿠킹에서 이전 artifact를 병합, `CookProject`가 프로필에서 채움.
- EngineAssets `EngineAssetsSubsystem::Manifest()`.

A4f3으로 넘기는 것: 이번 쿠킹이 만든 artifact가 같은 키의 이전 항목을 이기는 병합(단계가 생겨야 항목이 생긴다), 이어받은 artifact의 파일 대조(10.3절 6항), `Shaders/` 정리.
