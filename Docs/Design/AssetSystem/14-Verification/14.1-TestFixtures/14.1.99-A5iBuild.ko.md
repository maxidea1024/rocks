#### 14.1.99 요구 대조표(A5i — 텍스처 빌드)

명세는 [12.13절](../../12-Textures/12.13-A5iBuild.ko.md)이고, 규칙은 UE 5.8에 맞춰 개정한 12.5절·12.2절 1–5번·12.4.3절이다.

구현:
- TextureTools `Private/TextureBuild.cpp`, `Public/TextureTools/TextureBuild.h`.
- AssetRuntime 진단 `SrgbIgnored`·`PreserveBorderWithWrap`.

시험은 TextureTools `Tests/TextureBuildTests.cpp`다. `PackageLoadTests.cpp`의 진단 이름표가 새 코드까지 넓어졌다.

빌드 때 더할 것(화면 마일스톤 뒤 — 미빌드):
- 컴파일·경고 0, 위 시험 실행.
- UE 결과 대조 픽스처: 같은 원본을 UE 5.8로 쿠킹한 mip(2×2 상자·PreserveBorder·NormalizeNormals·쿠킹 편향은 byte 일치 기대). 재표본(stb_image_resize2 — float 계산·조건부 정규화·축 순서 선택)은 byte 차이를 확인해 허용 오차를 적는다. 8비트 선형 디코딩 식도 대조한다.
- Float16 하드웨어(F16C)·소프트웨어 경로의 subnormal·NaN 일치.
- coverage를 잰다.

리뷰 반영(2026-11-24, 필수 4·권장 8): 같은 길이 축은 point 표본(UE FilterIsNopWhenSameSize), 재표본 결과를 자르지 않음, flipGreen을 최대 크기 뒤 Clamp 후 뒤집기(UE 3176·4603), 최대 크기 2×2 경로가 Unfiltered를 따름, 8비트 sRGB 부호화를 UE stb 표 변환으로·양자화를 UE float 식으로, BuildTexture의 slice 수·mipGen 검사, LODBias 합·편향 계산의 int32 넘침 방지, Resample이 X 단계 뒤 원본을 놓음, UE와 다른 곳(stbir 정규화·Availability CPU placeholder·16384 넘는 Resize + LODBias·8비트 선형 디코딩 식)을 12.13절에 적음. 빠진 시험 가운데 할당 실패 전수의 Pad·최대 크기 경로와 21행 채널 값 전부는 빌드 때 더한다.
