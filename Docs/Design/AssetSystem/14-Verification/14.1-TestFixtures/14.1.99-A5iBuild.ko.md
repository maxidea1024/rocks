#### 14.1.99 요구 대조표(A5i — 텍스처 빌드)

명세는 [12.13절](../../12-Textures/12.13-A5iBuild.ko.md)이고, 규칙은 UE 5.8에 맞춰 개정한 12.5절·12.2절 1–5번·12.4.3절이다.

구현:
- TextureTools `Private/TextureBuild.cpp`, `Public/TextureTools/TextureBuild.h`.
- AssetRuntime 진단 `SrgbIgnored`·`PreserveBorderWithWrap`.

시험은 TextureTools `Tests/TextureBuildTests.cpp`다. `PackageLoadTests.cpp`의 진단 이름표가 새 코드까지 넓어졌다.

| 요구 | 항목 | 시험 |
|---|---|---|
| mip 규칙(12.5절) | 2×2 상자(4×4·5×3 홀수 끝 버림·1×7 길이 1 축), Volume slice 평균(2×2×2·3×3×3), 2DArray slice별, Unfiltered (2i, 2j) | `TextureBuild_SimpleAverage`·`_VolumeArrayAndUnfiltered` |
| PowerOfTwoMode | Pad(sRGB 채움 색·테두리·Square·Volume Z), Stretch 올림(3 → 4·5 → 8·Square·Volume은 X·Y만), Resize 0 축, Cube 정사각 깸 InvalidSetting, 비정사각 Cube InvalidSource | `TextureBuild_PowerOfTwoMode` |
| 재표본 | Catmull-Rom 확대·Mitchell 축소·같은 길이 축 Mitchell 기준값(Python 같은 식), 정수 자르기·float 음수 유지 | `TextureBuild_AdaptiveSharp` |
| 최대 크기·쿠킹 편향 | LODBias·음수, MaxTextureSize 재표본 + LODBias 합, 그룹 MaxLODSize·MinLODSize CeilLog2(100 → 128, Min > Max), NoMipmaps(편향 없음·그룹 MaxLODSize 무시), Volume X·Y 편향·Z 사슬 | `TextureBuild_LodComposition` |
| 선형화 | sRGB·legacy gamma·선형·override Linear·sRGB, 16비트 선형·override sRGB, 알파 선형, flipGreen | `TextureBuild_Linearization` |
| 출력 | 종류 21행 × 원본(형식·swizzle), GA → RG, sRGB R8·RG8 확장·RGBA8 sRGB, SrgbIgnored(선형 종류·float → float), 16비트 SRGB on(16비트 출력·경고 없음), HDR_Compressed 알파 1 | `TextureBuild_OutputFormats` |

| 결정성·자원 | 같은 입력 두 번 같은 byte, 할당 실패 전수 | `TextureBuild_DeterminismAndAllocation` |

빌드 때 더할 것(화면 마일스톤 뒤 — 미빌드):
- 컴파일·경고 0, 위 시험 실행.
- UE 결과 대조 픽스처: 같은 원본을 UE 5.8로 쿠킹한 mip(2×2 상자·PreserveBorder·NormalizeNormals·쿠킹 편향은 byte 일치 기대). 재표본(stb_image_resize2)은 같은 길이 축의 Mitchell 적용 여부와 byte 차이를 확인해 허용 오차를 적는다.
- Float16 하드웨어(F16C)·소프트웨어 경로의 subnormal·NaN 일치.
- coverage를 잰다.
