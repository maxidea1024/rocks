#### 14.1.103 요구 대조표(A5j2a — 텍스처 원본 묶음)

명세는 [12.14절 A5j2](../../12-Textures/12.14-A5jCook.ko.md)다.

구현:
- AssetRuntime `AssetTypeHooks.h/.cpp`: hook 종류 `rebuildSource`(`AssetSourceRebuildHook`), `AssetSourceRebuildSink`(ReadBulk·AddBulk·HasImportRecord·Cause·ChangedSource·Fail·Warn), `AssetSourceRebuildCause`, `AssetTypeHookTable::RebuildSource`·`CallBaseRebuildSource`. 진단 `SourceCleared`(경고).
- AssetDatabase:
  - `EditorPackageSet::RebuildSource`(sink 구현 — 원소의 열린 패키지 bulk 저장소 읽기, 대상 패키지 AddUnsaved). 경고 종류 `SourceRebuildWarning`.
  - `AssetService::Set`은 정규화 앞에서 Edit로 부른다.
  - `AssetService::New`는 원본 재구성 → 정규화 순으로 부르고(New가 정규화를 부르게 됨), 실패하면 패키지를 닫는다.
  - `RunImportGroup`의 재임포트 전파: 색인 EditorOnly 역참조를 열어 Propagate로 부르고 정규화하며, 원소 뒤에 저장한다.
- AssetCommandlets: 경고 이름 `SourceRebuildWarning`.
- TextureTools `Private/TextureSourceRebuild.cpp`: Texture2DArray·TextureCubeArray·VolumeTexture hook. `RegisterTextureTypeHooks`가 함께 등록한다.

시험:
- TextureTools `Tests/TextureSourceRebuildTests.cpp`(가짜 sink — hook 규칙).
- AssetDatabase `Tests/AssetImportTests.cpp`의 `AssetImport_RebuildSourceHook`(서비스 연결).
- 이름표 `AssetPackage_DiagnosticNames`(SourceCleared까지).

| 요구 | 항목 | 시험 |
|---|---|---|
| 2DArray 잇기 | mip 0 byte를 원소 순으로(byte 위치 대조), slice·mip 1·형식·크기, 배열 SRGB = 첫 원소 sRGB 여부, 처음 만들기 설정 다섯(대입한 lodGroup은 둔다), 원본이 있던 배열은 설정 불변, 묶음 필드가 없으면 아무것도 안 함, 대문자 필드 이름 | `TextureSourceRebuild_ArrayConcat` |
| CubeArray | 6면 × 2 → slice 12·byte 수, 6면이 아닌 원소 InvalidSetting(번호), 상한 42(43개 거부·detail 42) | `TextureSourceRebuild_CubeArray` |
| 원소 판정 | null InvalidSetting·원본 없음 InvalidSource·크기·형식·legacy gamma sRGB 불일치·numLayers UnsupportedSetting(모두 detail = 번호·원본 불변), G16 + SRGB on은 선형(G16 off와 섞임·배열 SRGB off), byte 한도 CapacityExceeded(읽기 전), 빈 목록 → 빈 원본, 임포트한 배열(빈 목록은 그대로·묶음 대입 거부) | `TextureSourceRebuild_ArrayChecks` |
| Propagate | 바뀐 원소를 가리킬 때만 다시 복사(대입 필드 없이) | `TextureSourceRebuild_Propagate` |
| Volume | 기본 타일(8×8 → 4×4·깊이 4, 10×27 → 5×13·깊이 4), 타일 순서 byte, 명시 타일(깊이 16), 512 상한, 타일 0·음수 → 빈 원본 + SourceCleared, Propagate는 타일 유지, asset-new 기본 원본 1×1 RGBA8 (0, 0, 0, 255), 임포트한 Volume 보호 | `TextureSourceRebuild_Volume` |
| 서비스 | 임포트는 부르지 않음, asset-new New 까닭·대입 필드·저장 전 적용, New 실패 진단 그대로·파일 없음·같은 경로 다시 New, asset-set Edit·실패 진단 그대로·저장 안 함, 재임포트 전파 Propagate·바뀐 원소 id·묶음 저장, 전파 실패면 재임포트 실패·원소·묶음 저장 안 함 | `AssetImport_RebuildSourceHook` |

빌드 때 더할 것(화면 마일스톤 뒤 — 미빌드):
- 컴파일·경고 0, 위 시험 실행.
- 실제 텍스처 에셋으로 `asset-new Texture2DArray … SourceTextures=…`·`--reset=sourceTextures`·원소 `asset-reimport` 명령 시험과, 복사한 원본으로 쿠킹(A5j1 처리기 — Build 의존 없음) 확인.
- Volume 기본 타일을 UE 5.8 결과와 대조(powf 경계).
- 할당 실패 전수(hook·sink·전파).
- coverage를 잰다.

#### 14.1.104 Coverage(A5j2a)

빌드 재개 때 잰다. 대상은 `TextureSourceRebuild.cpp` 전체, `EditorPackageSet::RebuildSource`·sink, `AssetService::Set·New`의 바뀐 갈래, 재임포트 전파다.
