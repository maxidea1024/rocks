#### 14.1.101 요구 대조표(A5j1 — 텍스처 쿠킹)

명세는 [12.14절](../../12-Textures/12.14-A5jCook.ko.md)이다.

구현:
- AssetCooker `CookConfig.h/.cpp`: TargetProfile 텍스처 칸(`TextureLodGroup` struct·enum 둘, `textureLodGroups`, `textureNorm16Supported`), MergeByKey 병합, 그룹 검증, `FindTextureLodGroup`.
- AssetCooker `CookProcessor.h`·`CookRun.h/.cpp`: `CookContext::warnings`, 실행 진단으로 옮기기, 경고를 빼고 세는 `CookRunResult::HasErrors`.
- AssetCommandlets: `AssetCookProcessorSetup`(`AssetCommandContext::cookProcessors`), asset-cook의 등록 호출, LOD 그룹 실패 문구.
- TextureTools `Public/TextureTools/TextureCook.h`·`Private/TextureCook.cpp`: `TextureCookProcessor`, 너겟 머리, R, 샘플러 필터, `RegisterTextureCookProcessors`.
- TextureTools `TextureBuild.h/.cpp`: `TextureBuildVersion`, `TextureBuildWarnings`, `TextureBuildOutput`, norm16 대체(Unorm16 → 16F, [0, 1] 자르기).
- Texture `TextureBuildSettings.h`(리플렉션 struct, `norm16Supported`).
- AssetRuntime 진단 `NuggetConflict`(경고). Core `ErrorCode::IoError`(원인 오류 없는 입출력 실패 — 사용자 지시 2026-11-25).
- 엔진 프로파일 `Engine/Config/TargetProfiles/Windows.json`·`Android.json`(UE 5.8 GlobalDefaults 27행, Android norm16 false).
- 호스트 `CommandletHost.cpp`가 처리기를 건다.

시험:
- AssetCooker `Tests/CookConfigTests.cpp`의 `CookConfig_TextureProfile`.
- AssetCooker `Tests/CookRunTests.cpp`의 `CookRun_ProcessorWarnings`.
- TextureTools `Tests/TextureCookTests.cpp`.
- 이름표 시험 `AssetPackage_DiagnosticNames`(NuggetConflict까지)·`ErrorCodeNamesAreCompleteAndUnique`(IoError까지).

빌드 때 더할 것(화면 마일스톤 뒤 — 미빌드):
- 컴파일·경고 0, 위 시험 실행(리플렉션 생성 소스가 새 struct·enum·칸을 만든다).
- `asset-cook --profile=Windows`의 텍스처 쿠킹 명령 시험(제품 호스트 연결 — AssetCommandlets 시험 호스트에 처리기 등록을 걸어), 할당 실패 전수(처리기·프로파일 읽기).
- `required` 캐시의 Get·Put·Reject 실패(오류 주입 파일 시스템), Put의 `NuggetConflict` 경고(다른 프로세스가 Get과 Put 사이에 다른 값을 쓴 경쟁 — 주입 hook이 필요하다), 미리 열린 패키지를 쿠킹한 뒤 에디터 저장 byte가 쿠킹 전과 같음(CookRun `before_` 경로), 다른 bulk를 가진 export가 섞인 패키지(연쇄 bulk 원본의 에디터 쪽 ref).
- `TextureBuildVersion`·처리기 버전 Guid 변이(상수라 시험 안에서 바꿀 수 없다 — 키 기록 순서를 trace 줄로 고정하는 golden으로 대신한다).
- coverage를 잰다.

리뷰 반영(2026-11-25, 필수 1·권장 5 — 4 반영·1 후속): CPU 행 기대값(N 1), 적중 검증에 사슬 끝 검사, 거부한 적중 Record를 `NuggetCache::Reject`로 치움(새 API — 9절 A3c1), 키 사본의 주소 고정·norm16 정규화(출력이 바뀔 때만), 채우기 전 `mips` 비움, 연쇄 bulk id 범위 검사. SHA-256 세 번 계산은 12.14절 한계로 적고 후속 성능 개선이다. 참고 의견 가운데 편향을 키에 넣는 UE와의 차이(UE는 전체 사슬을 두고 직렬화 때 자른다)는 12.14절에 적었다. `TextureBuildSettings`는 에셋 명령 세션이 등록하는 Texture 모듈에 둔다(임포트 옵션과 같은 까닭 — 헤더 주석).
