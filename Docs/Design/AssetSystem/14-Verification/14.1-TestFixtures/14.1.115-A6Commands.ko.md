#### 14.1.115 요구 대조표(A6 — asset-load-cooked·nugget-gc)

명세는 [13.1절](../../13-CommandLine.ko.md)과 9.1절 9항(GC)이다.

구현:
- AssetCommandlets:
  - `asset-load-cooked`(`AssetLoadCookedCommandlet.cpp`): 쿠킹 루트 매니페스트, EngineAssets와 같은 로더 구성(IO·실행기·AssetManager — worker 1·IO 1 고정), 경로 힌트·AssetId 대상, `LoadBlocking`, 성공·실패 줄.
  - `nugget-gc`(`NuggetGcCommandlet.cpp`): 너겟 설정, off·rockpile, 로컬 backend Open·읽기 전용, `Collect`, 결과 줄.
  - 두 명령은 CommandletHost에 등록했다.
- AssetNugget `Collect`: 읽기 전용이면 Unsupported, tick으로 넘치는 일수는 나이 제한 없음(`NuggetCollectMaxUnusedDays`).

| 요구 | 항목 | 시험 |
|---|---|---|
| 로드 성공 | 경로 힌트(대소문자 다르게)·AssetId로 성공 줄(packages 2 — 대상과 Hard 의존) | `AssetLoadCookedCommand_LoadsAndRejects` |
| 로드 실패 | 없는 경로 NotFound 줄, 매니페스트 없음(다른 프로필), 프로필이 다른 매니페스트 IncompatibleCook, 패키지 손상 CorruptPackage | `AssetLoadCookedCommand_LoadsAndRejects` |
| 로드 사용법 | 대상 없음·둘, 잘못된 AssetId, 프로필 없음·두 번 → 2 | `AssetLoadCookedCommand_LoadsAndRejects` |
| GC | 큰 상한(u64 최대·일수 u32 최대 포화)은 남김, `--max-bytes=0`은 지움(결정적), 결과 줄 | `NuggetGcCommand_CollectsAndRejects` |
| GC 설정 | off 줄(0), rockpile Unsupported(1), 설정 문법 오류 InvalidSetting, 읽기 전용 루트(tmp 자리가 파일) Unsupported | `NuggetGcCommand_CollectsAndRejects` |
| GC 사용법 | 옵션 빠짐 둘, 문법(문자·음수), u32·u64 넘침, 두 번, 위치 인자 → 2 | `NuggetGcCommand_CollectsAndRejects` |
| backend | 일수 포화(u32 최대 → 나이로 지우지 않음), 읽기 전용 Collect Unsupported(Get은 그대로 적중) | `NuggetBackend_TouchRemoveAndCollect`·`NuggetBackend_OpenAndReadOnly` |

빌드 때 더할 것(화면 마일스톤 뒤 — 미빌드): 시험 실행, 14절 시나리오 결과 기록(A6 완료 조건), coverage 사유.
