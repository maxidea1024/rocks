## 17. 버린 대안과 후속

- **엔진 UI(UiToolkit)로 그리기.** 그래픽 장치·글꼴 시스템이 선 뒤에야 그릴 수 있어 가장 긴 구간(모듈·장치 시작)을 덮지 못한다. 사용자 정의 시작 화면은 UE `PreLoadScreen`처럼 따로 설계한다.
- **`ImageCodec`이나 자체 PNG 디코더.** Developer 모듈은 출시 게임에 못 들어가고, 런타임 디코더를 따로 두면 OS가 이미 주는 것을 중복한다.
- **스플래시 이미지를 쿠킹 에셋(텍스처)으로.** 에셋 시스템 시작 전에 필요하다.
- **UI 펌프 hook으로 갱신(UE 방식).** 호스트 스레드가 긴 외부 호출에 막히면 멈춘다.
- **페이드.** UE도 끈 채 둔다(`bAllowFading = false`). 최소 표시 시간은 개정 4에서 채택했다(9.7절 — 처음에는 시작을 늦춘다는 이유로 버렸다).
- **모니터 배율 변경 때 다시 그리기.** 짧게 사는 창이라 이득이 적다.
- **후속**: 비사각(alpha) 창, macOS Dock 진행, Linux(BS6과 함께), 마지막 주 창 위치의 모니터에 띄우기, 스플래시 위 사용자 정의 이미지 칸(UE `SplashImageType::User*`).
