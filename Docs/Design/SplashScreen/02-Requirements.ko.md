# 시작 화면(스플래시) — 2. 요구

[목차](README.ko.md)

## 2. 요구

1. **데스크톱 게임·Studio·엔진 프로그램 모두.** 같은 모듈이 Game 대상(패키징된 게임 포함)과 Studio, Sandbox 같은 엔진 창 프로그램을 덮는다. 엔진(Studio)과 프로젝트(게임)의 이미지는 따로다.
2. **진행 표시는 필수.** 막대는 늘 보이고(설정으로 끌 수만 있다), 뒤로 가지 않으며, 주 스레드가 오래 막혀도 문구와 막대가 갱신된다.
3. **끌 수 있다.** 실행 한 번(명령줄), 프로젝트 전체(프로젝트 설정), 사용자(사용자 층 설정), 그리고 사람이 보지 않는 실행(무인·headless·시험·도구)은 자동으로 끈다.
4. **빨리 뜬다.** 설정·로그 준비 직후에 띄운다(UE와 같은 자리). 목표는 Development에서 프로세스 시작 뒤 150 ms 안(측정 기록, 시험 단언 아님).
5. **주 창으로 자연스럽게 넘어간다.** 주 창이 첫 프레임을 보인 뒤 사라지고, 주 창이 앞에 온다. 빈 화면 틈이 없다.
6. **시작을 방해하지 않는다.** 스플래시 실패(이미지 없음·창 실패)는 경고 한 줄이고 시작은 계속한다. 대화상자를 가리지 않는다.
7. **결정적 시험.** 표시 여부·이미지 고르기·배치·진행 문구·막대 보간·보정은 OS 창 없이 주입 시계로 시험한다.
