# 머티리얼 시스템(MaterialSystem) 설계

## 6. IR — MS2d 구현 세부

### 6.11 MS2d 구현 세부(표면·대표 노멀·추가 출력)

근거는 UE 5.8 Substrate(`MaterialExpressionSubstrate.cpp`(MES)·`SubstrateTranslatorCommon.cpp`(STC)·`Substrate.ush`(S)·`SubstrateExport.ush`(SE)·`SubstrateLegacyConversion.ush`(SLC))와 고전 경로(`HLSLMaterialTranslator.cpp`(HT)·`MaterialTemplate.ush`(MT)·`MaterialAttributeDefinitionMap.cpp`(MADM))다. Rocks 렌더러는 UE Blendable처럼 픽셀당 closure 하나다(10.3절, Renderer 7.1절). 그래서 번역은 언제나 표면 트리를 closure 하나로 접는다.

| 묶음 | 내용 |
|---|---|
| MS2d1 | 표면 기반: 표면 기록·IR `SurfaceRef`, 출력 노드 `Surface` 핀, 내보내기(`SurfaceAttributes` — `subsurfaceColor` 추가), `SurfaceFromShadingModel`·`ShadingModel` 노드, shading model 집합 정의, 대표 노멀 진입점(`EvaluateMaterialNormal`)·순환 검사, AO 활성 좁히기, 영역 표면(LightFunction·PostProcess·UserInterface·ToDecal·VolumetricFogCloud)·Unlit |
| MS2d2 | BSDF·연산: Slab·SimpleClearCoat·Hair·Eye·SingleLayerWater, 연산(HorizontalMix·VerticalLayer·Add·Weight·Select) parameter blending, 고전 preset → slab 변환(연산 아래의 preset), 도우미 넷(TransmittanceToMeanFreePath·MetalnessToDiffuseAlbedoF0·HazinessToSecondaryRoughness·ThinFilm), Toon TODO |
| MS2d3 | 추가 출력 노드·custom 출력 진입점(번호별 함수·존재 정의·정점 빈도), MaterialCache TODO |

`SurfaceFromAttributes`는 MaterialAttributes 값(MS2e)을 받으므로 **MS2e로 옮긴다**(15장 단계 표를 고친다). MS2d 동안 이 노드는 `NotYetLowered`다.

**MS2d1 표면 기반.**
- **표면 값.** 표면 핀(타입 `Surface`)의 값은 IR 값 `SurfaceRef`(번호 91, 타입 `IrScalar::Surface`(6) 성분 1 — 산술·변환·선택에 들어가지 못한다(V1), 텍스처와 같은 규칙)다. 즉시값 [0]이 번역기 표면 기록 번호다. 기록은 노드 하나의 표면이다: BSDF 종류(Slab·Unlit·Hair·Eye·SingleLayerWater·VolumetricFogCloud·영역 표면·고전 preset), 매개변수(IR 값 번호), 기능 표지(EdgeColor·Fuzz·SecondRoughness·SimpleClearCoat·SSS 종류·MFP·Anisotropy·Glint·Thin), 노멀·tangent, coverage, 연산이면 자식 기록 둘과 연산 매개변수다. 기록은 트리 그대로 남고(10.3절 "IR의 Surface 타입은 처음부터 트리"), 접기는 출력 노드에서 한다(여러 closure gate가 열리면 접기만 바꾼다). 늦은 진단 자리 값(Pending)이 표면 핀에 오면 그 자리가 표면 기록의 자리 값이 된다(그 노드 진단은 결과에서 닿을 때 — 6.10절 MS2c1).
- **ShadingModel 값.** `ShadingModel` 핀 타입은 IR `UInt1`(Renderer 14.2절 번호)이다. `ShadingModel` 노드는 그 상수다. Rocks 번호표에 없는 preset(PreintegratedSkin — Renderer 14.2절이 SubsurfaceProfile로 대신, FromMaterialExpression)은 노드 위치 InvalidProperty "Shading model is not supported: <이름>"이다.
- **SurfaceFromShadingModel(고전 preset).** UE `SubstrateShadingModels`의 고전 입력을 그대로 지나가게 한다(10.3절 "변환 없이"). 입력 기본값은 UE `CompileCommon`(MES:232–377)과 같다: BaseColor 0, Metallic 0, Specular 0.5, Roughness 0.5, Anisotropy 0, Emissive 0, Normal 대표 노멀 규칙(아래), Tangent 정점 tangent, SubSurfaceColor 1(shading model 집합(상수면 그 하나, ShadingModel 입력이면 닿는 상수)에 TwoSidedFoliage가 있으면 0 — MADM:50–55), ClearCoat 1, ClearCoatRoughness 0.1, Opacity 1, TransmittanceColor 0.5, ThinTranslucentSurfaceCoverage 1, 물 계수 0·PhaseG 0·ColorScaleBehindWater 1, ClearCoatNormal = Normal, CustomTangent = Normal. ShadingModel 입력이 연결되면 그 값(픽셀마다 — UE `SetShadingModelFromExpression`), 아니면 속성 `shadingModelOverride`다. 물·얇은 투과·clear coat 아래 노멀·custom tangent 입력은 UE 고전 경로처럼 custom 출력으로 낸다(MS2d3 — ThinTranslucent·SingleLayerWater·ClearCoatNormal·Tangent 출력과 같은 진입점, 연결된 것만).
- **내보내기 대상.** `SurfaceAttributes`는 UE 고전 픽셀 속성(`FPixelMaterialInputs`)과 같은 칸이다: baseColor·metallic·specular·roughness·anisotropy·emissive·opacity·opacityMask·normal·tangent·**subsurfaceColor**(추가 — UE `MP_SubsurfaceColor`, Subsurface·TwoSidedFoliage·Cloth의 색)·customData0·customData1·ambientOcclusion·shadingModel. GBuffer 배치는 렌더러가 고전 규칙(UE `SetGBufferForShadingModel`)으로 한다. `subsurfaceColor` 칸 추가는 Renderer 14.1절 개정 요청이다(16절 MRD17). 칸 값은 UE 템플릿처럼 생성 원문이 saturate한다(baseColor·metallic·specular·roughness·AO·opacity·subsurfaceColor saturate, anisotropy clamp(−1, 1) — MT:3778–4146). 예외: VolumetricFogCloud의 subsurfaceColor(Extinction, 1/m)는 saturate하지 않는다(UE 볼륨 경로는 원값 `GetMaterialSubsurfaceDataRaw`를 읽는다 — MT:4102, VolumetricFogVoxelization.usf:37).
- **내보내기 식(slab → 고전, UE SE:1058–1312·S:3822–4110).** 접은 slab에서: metal = saturate((max3(F0) − 0.08)/0.32), baseColor = lerp(DiffuseAlbedo, F0, metal), specular = saturate(max3(F0)/0.08), roughness는 SimpleClearCoat가 아닌 haze를 lerp(Roughness, HazeRoughness, HazeWeight)로 굽고, F90이 있으면 UE `SubstrateBakeF90ToReflectivity`(NoV = saturate(dot(정점 노멀, CameraVector)))로 F0에 굽는다. emissive = Emissive × coverage. shading model과 칸은 UE 우선순위 사슬(SE:1137–1300)이다:

| 조건(위가 우선) | shading model | 칸 |
|---|---|---|
| Hair | Hair | metallic = Scatter, customData0 = Backlit(고전 MP_CustomData0) |
| Eye | Eye | customData0 = IrisMask, customData1 = IrisDistance, IrisPlaneNormal은 TangentOutput 출력(고전 Eye GBuffer가 `GetTangentOutput0`을 읽는다 — ShadingModelsMaterial.ush:160–166) |
| SSS profile | SubsurfaceProfile | opacity = RadiusScale(TODO MPQ-SubsurfaceProfile — profile 에셋이 없으므로 속성 값이 있으면 PrerequisiteMissing) |
| SSS Wrap | Subsurface | subsurfaceColor = exp(−1/max(ε, MFP_cm·0.01)), opacity = 1 − abs(PhaseAnisotropy)(SE:1251 → SubstrateSubsurface.ush:73) |
| SSS TwoSidedWrap | TwoSidedFoliage | 같다 |
| Fuzz | Cloth | subsurfaceColor = FuzzColor, customData0 = FuzzAmount |
| SimpleClearCoat haze | ClearCoat | customData0 = HazeWeight, customData1 = HazeRoughness |
| Thin(얇은 투과, slab IsThin) | ThinTranslucent | Rocks 10.3절 표(UE Blendable은 DefaultLit로 낸다 — 편차, Renderer 14.2절 ThinTranslucent를 쓴다) |
| 그 밖(SSS Diffusion·SimpleVolume 포함 — UE Blendable과 같다) | DefaultLit | — |
| Unlit·영역 표면 | Unlit | emissive만 |

  - SingleLayerWater는 slab 사슬 밖 전용 BSDF다: baseColor·metallic(UE 내보내기는 0 — S:3965 그대로)·specular·roughness·emissive, shading model SingleLayerWater, 물 계수는 custom 출력(MS2d3).
  - 고전 preset이 연산 없이 뿌리에 바로 이어지면 내보내기 식을 거치지 않고 그 고전 입력을 그대로 칸에 쓴다(10.3절 — UE Blendable의 FrontMaterial 없는 고전 컴파일과 같은 결과).
- **shading model 집합.** 내보낸 shadingModel이 상수면 그 하나, 연결된 ShadingModel 입력·Select로 갈리면 static으로 닿는 상수들의 합집합이다(UE `ShadingModelsFromCompilation` — 상수가 아닌 값(파라미터 등)이 섞이면 Rocks 번호표 전부). 생성 원문은 `#define MATERIAL_SHADING_MODELS <비트>u`와, 하나뿐이면 `#define MATERIAL_SINGLE_SHADING_MODEL <번호>`(여럿이면 정의하지 않는다 — UE `MATERIAL_SINGLE_SHADINGMODEL`과 같다)를 낸다. 번역 결과 `MaterialTranslation.shadingModels`(비트)에도 담는다(8.3절 `MaterialShaderTraits` — 쿠킹이 거르기에 쓴다).
- **대표 노멀(19.3.3절).** 새 진입점 `IrEntry::Normal`(픽셀)과 생성 함수 `float3 EvaluateMaterialNormal(in MaterialInputs c)`를 둔다. 값은 접은 표면의 world 노멀(정규화)이다: shading model을 정하는 BSDF(접은 slab이면 parameter blending으로 섞은 노멀 — UE `SubstrateBlendNormal`)의 Normal 입력, 연결이 없으면 정점 노멀이다. 연결된 Normal은 `tangentSpaceNormal`이면 tangent 기저로 world로 바꾸고(UE `TransformNormalFromRequestedBasisToWorld`) 정규화한다. pass는 UE `CalcPixelMaterialInputs`처럼 이 함수를 먼저 불러 `c.pixelNormal`을 채운 뒤 다른 함수를 부른다(7.3절 개정). `PixelNormal`·`ReflectionVector`·`Fresnel`은 지금처럼 `c.pixelNormal`을 읽는다. **순환 검사(V2)**: Normal 진입점(그리고 MS2d3의 ClearCoatNormal·Tangent·BentNormal 출력)에서 `PixelNormal` 문맥 값이나 그것을 읽는 값이 닿으면 "Invalid node PixelNormalWS used for Normal input."(UE HT:11784–11787)이다. UE보다 넓은 규칙이다(UE는 MP_Normal만 — 19.3.3절).
- **Surface 진입점.** `EvaluateMaterialSurface`는 칸마다 결과(entry Surface, slot = 칸 이름)를 쓴다. normal 칸은 대표 노멀 값(같은 IR 값 — hash-consing으로 한 번 계산), tangent 칸은 접은 tangent(연결 없으면 정점 tangent, tangent 공간이면 world로)다. 결과가 없는 칸은 `DefaultSurfaceAttributes()` 값이다.
- **opacity.** 표면 opacity(preset Opacity·영역 표면 Opacity·Decal coverage)는 Surface 진입점 slot `SurfaceOpacity`(`s.opacity` — SSS 값)다. 반투명이고 Opacity 출력 핀이 쓰이지 않으면(AlphaComposite 밖 — UE Substrate는 coverage가 opacity다) 같은 값이 Opacity 진입점(`EvaluateMaterialOpacity`)도 된다.
- **AO 활성.** AmbientOcclusion 핀은 영역 Surface·DeferredDecal이고 shading model이 lit일 때만 활성이다(UE Material.cpp:7929–7930 — 집합이 Unlit 하나면 비활성, V5 경고).
- **영역 표면.** UE처럼 Unlit BSDF로 낮춘다(MES 1.8–1.11): LightFunction → emissive = Color, PostProcess → emissive = Color·opacity = Opacity, UserInterface → UE `SubstrateCreateUIMaterial`(블렌드 모드별: Additive emissive = Color·Opacity, Modulate emissive 0·opacity 칸 없이 transmittance = Color — Rocks는 emissive = Color로 두고 블렌드는 pass가 한다(편차 기록), 그 밖 emissive = Color·opacity = Opacity), ToDecal → 자식 slab을 내보내고 opacity = Coverage(UE `SubstrateWeightParameterBlending` — 자식은 slab만, 아니면 UE 문구 오류), VolumetricFogCloud → baseColor = Albedo, subsurfaceColor = Extinction(UE 고전 Volume 칸), emissive, ambientOcclusion = AO(emissiveOnly면 Albedo·Extinction 0, AO 1). 영역과 맞지 않는 표면(예: Surface 영역의 PostProcess 표면)은 V6 "Surface node is not valid for the material domain"이다(UE는 Substrate 트리 검증이 거른다).

**MS2d2 BSDF·연산.**
- **BSDF 입력 기본값**은 UE Compile 값이다(조사표 — Slab: DiffuseAlbedo 0.18, F0 0.04, F90 1, Roughness 0.5, Anisotropy 0, SSS MFP 0·Scale 1·PhaseAnisotropy 0, Emissive 0, SecondRoughness 0·Weight 0, FuzzRoughness = Roughness(연결 없으면), FuzzAmount 0·FuzzColor 0, Glint 1, GlintUV 0; SimpleClearCoat: Coverage 1·ClearCoatRoughness 0.1·BottomNormal = Normal; Hair: BaseColor 0·Scatter 0·Specular 0.5·Roughness 0.5·Backlit 0; Eye: DiffuseColor 0·Roughness 0.5·IrisMask 0·IrisDistance 0, CorneaNormal은 UE처럼 정점 tangent 기본(MES:2237); SingleLayerWater: BaseColor 0·Metallic 0·Specular 0.5·Roughness 0.5·TopMaterialOpacity 0·WaterAlbedo 0·Extinction 0·PhaseG 0·ColorScaleBehindWater 1; Unlit: Emissive 0·Transmittance 1).
- **기능 표지**는 UE `SubstrateGenerateMaterialTopologyTree`(MES:1230–1250)와 같다: EdgeColor ⇐ F90 연결, Fuzz ⇐ FuzzAmount 연결, SecondRoughness ⇐ SecondRoughnessWeight 연결(또는 profile), SSS ⇐ profile 또는 MFP 연결, Anisotropy ⇐ Anisotropy 연결, Glint ⇐ GlintValue 연결. 표지가 없으면 그 매개변수를 UE "simplification"대로 기본으로 둔다(MES:898–926). SSS 종류: subSurfaceType 속성, MFP가 없으면 None, 연산의 위층(bottom 아님)은 SimpleVolume(S:1595–1607).
- **접기.** 연산은 모두 parameter blending이다(UE Blendable은 closure 1이라 연산을 깊은 것부터 전부 blending으로 바꾼다 — STC:623–1433. 결과가 같으므로 한 번에 전부 바꾼다). 식은 UE S:2853–3361과 같다(입력 slab은 먼저 F90·glint를 F0에 굽는다, c = saturate(Coverage)):
  - Horizontal: w = c_F·m/max(ε, c_F·m + c_B·(1 − m)), m = saturate(Mix). 색·F0·F90·거칠기·anisotropy·fuzz·haze·MFP·두께 = lerp(B, F, w). 표지 OR, SSS 종류 max. Coverage = lerp(c_B, c_F, Mix(saturate 전 — UE 그대로)). 노멀 = normalize(lerp(N_B, N_F, w)).
  - Add: a = c_A/max(ε, c_A + c_B). Emissive 합, DiffuseAlbedo·F0·F90·FuzzColor saturate(합), 나머지 lerp(B, A, a). Coverage = saturate(c_A + c_B). PhaseAnisotropy는 UE처럼 0. 노멀 = normalize(lerp(N_B, N_A, a)).
  - Vertical: UE 층 정보(TTB = c_T·c_B, TOB = (1 − c_T)c_B, Coverage = c_T + TOB), 위층 slab 투과 Tslab(UE `IsotropicMediumSlabTransmittance`, 굴절 NoV), 위층 albedo는 UE ALU 근사(`IsotropicMediumSlabPunctualDirectionalAlbedo`의 LUT 없는 분기 — Rocks에 SimpleVolume LUT가 없다, 편차로 기록), L = saturate((TTB·avg(Tslab) + TOB)/Coverage)로 거칠기·fuzz·haze lerp(Top, Base, L), 색은 (TTB·Tslab + TOB)/Coverage·Base + c_T/Coverage·Top. anisotropy 0, SSS 종류 min(Base, Diffusion). 노멀 = normalize(lerp(N_Base, N_Top, saturate(c_T)·0.5)).
  - Weight: Coverage ×= saturate(Weight). Select: (SelectValue > threshold) ? B : A 전체(노멀·tangent도 같은 쪽 — UE는 tangent를 거꾸로 고르는 결함이 있다(MES:3370) — Rocks는 고친다, 편차 기록).
- **허용 표.** UE STC:388–394와 같다: Weight {Unlit·Slab·Toon}, Select {Slab·Hair·Eye·Toon}, Horizontal·Vertical·Add·ToDecal {Slab}. 어기면 UE 문구 "Substrate error: Operator <연산> cannot be used with the following data flowing through <BSDF 목록>."(V1 자리 — UnsupportedCapability). 고전 preset은 연산 아래에서 UE `SubstrateConvertLegacyMaterialDynamic`(SLC:153–524)으로 slab이 된다(DefaultLit·Subsurface·TwoSidedFoliage·Cloth·ClearCoat·ThinTranslucent — 조사표 식), Hair·Eye·SLW·Unlit preset은 그 전용 BSDF다.
- **SingleLayerWater**는 parameter blending에 쓸 수 없다(UE 문구 둘 — MES:2368–2375).
- **도우미**는 UE 식 그대로 IR로 펼친다(조사표 — TransmittanceToMFP, MetalnessToDiffuseAlbedoF0, HazinessToSecondaryRoughness, ThinFilm). ThinFilm은 아래 "MS2d2 구현 세부"대로 IR로 펼친다(개정 26 — 새 IR 연산을 두지 않는다).
- `SurfaceToon`은 TODO(MPQ-ToonShading — 이미 `.Missing`) 늦은 진단, profile 속성(subsurfaceProfile·specularProfile)이 값을 가지면 그 노드 위치에 PrerequisiteMissing(MS-T12 (b)).

**MS2d2 구현 세부.** 세 묶음으로 나눈다: MS2d2a BSDF 다섯(Slab·SimpleClearCoat·Hair·Eye·SingleLayerWater)과 slab 내보내기, MS2d2b 연산 접기·허용 표·고전 preset 변환, MS2d2c 도우미 넷.
- **기록과 slab.** BSDF 노드 기록은 그 노드의 입력 값이다(UE "simplification"을 lowering에서 적용 — 표지 입력이 연결되지 않으면 그 매개변수는 기본값 상수). 접기에 쓰는 slab 값 묶음(`SurfaceSlab`: DiffuseAlbedo·F0·F90·Roughness·Anisotropy·Normal·Tangent·SSSMFP·VolumeMFP(UE `TmpMFP`)·PhaseAnisotropy·RadiusScale·Emissive·HazeRoughness·HazeWeight·FuzzRoughness·FuzzAmount·FuzzColor·Thickness·Coverage와 표지)은 출력 노드가 접을 때 만든다. 두께와 층 위치는 부모 연산이 정하기 때문이다(UE 두께 stack — VerticalLayer `Thickness`는 Top 쪽에만, Base는 부모 두께 — 와 `bIsBottom`). 같은 기록이 다른 경로로 닿으면 경로마다 따로 만든다.
- **표지는 IR 값.** UE는 매개변수 단순화는 연결로, 표지는 셰이더에서 값으로 정한다(S:1583–1665). Rocks도 같은 식을 IR로 펼친다: HasF90 = min3(F90) < 1, HasFuzz = FuzzAmount > 0, HasHaze = (HazeRoughness ≠ Roughness ∧ HazeWeight > 0) ∨ SimpleClearCoat, HasAnisotropy = Anisotropy ≠ 0, IsThin = 바닥 ∧ max3(MFP) > 0 ∧ `thinSurface` 속성. SSS 종류는 IR UInt(UE 번호 — None 0·Wrap 1·TwoSidedWrap 2·Diffusion 3·Profile 4·SimpleVolume 5)이고 UE 순서로 정한다: 반투명 블렌드면 Diffusion·Profile → None, 층 위(바닥이 아님)면 SimpleVolume, Diffusion이고 profile이면 Profile, MFP가 모두 0이면 None. 연결이 없는 흔한 경우는 모두 상수로 접혀 shading model 하나가 된다. 값으로 갈리면 내보내기 사슬이 IR Select라 shading model 집합은 닿는 상수의 합집합이다(MS2d1 규칙 그대로 — UE도 픽셀마다 정한다). 연산의 표지 병합(OR·max·min)도 IR 연산이다.
- **slab을 만들 때.** UE `InternalGetSubstrateSlabBSDF` 순서다: SSSMFPScale saturate, MFP = SSSMFP × Scale, Wrap·TwoSidedWrap이면 SSSMFP를 계산 공간으로 바꾼다(× 100/max(ε, 두께), 두께 100 cm — S:1650–1654), `TmpMFP`는 그 뒤의 SSSMFP다(S:1748), Coverage 1. glint는 Rocks 렌더러에 없으므로 UE 미지원 경로처럼 F0·F90 ×= saturate(GlintValue)로 굽고(S:1758–1768) GlintUV는 쓰지 않는다. haze 무게의 7 bit 양자화(PackHaziness)는 하지 않는다(GBuffer 배치는 렌더러 몫).
- **SimpleClearCoat**는 slab이다: F90 1, anisotropy 0, SSS None, fuzz 0(FuzzRoughness = Roughness), HazeRoughness = ClearCoatRoughness, HazeWeight = ClearCoatCoverage, SimpleClearCoat 참(MES:1357–1384). BottomNormal은 연결된 때만 MS2d3 `ClearCoatBottomNormal` 출력이 된다(UE `ClearCoatUseSecondNormal`).
- **Hair·Eye·SingleLayerWater 칸.** 전용 BSDF는 고전 칸으로 바로 낸다(UE 내보내기 사슬 SE:1137–1300 결과): Hair = baseColor·metallic = Scatter·specular·roughness·customData0 = Backlit·emissive·normal = Tangent 입력(UE는 hair tangent를 공유 기저 노멀로 쓴다 — MES:2137), shading model Hair. Eye = baseColor = DiffuseColor·metallic 0·specular 0.35(UE F0 0.028 → saturate(0.028/0.08))·roughness·customData0 = IrisMask·customData1 = IrisDistance·normal = CorneaNormal·emissive, shading model Eye, IrisNormal은 MS2d3 `ClearCoatBottomNormal` 출력, IrisPlaneNormal은 MS2d3 `TangentOutput` 출력(연결된 때만, tangent 칸은 정점 tangent — UE 고전 Eye는 GetTangentOutput0을 읽는다). SingleLayerWater = baseColor·metallic 0(S:3965)·specular·roughness·emissive·normal·opacity = TopMaterialOpacity(고전 SLW의 Opacity — SLC), shading model SingleLayerWater, 물 계수는 MS2d3 출력. Eye·SLW의 profile 속성은 값이 있으면 PrerequisiteMissing이다(MPQ-SubsurfaceProfile).
- **slab 내보내기 식.** SimpleClearCoat가 아닌 haze를 먼저 거칠기에 굽고(SubstrateBakeHazinessToSingleRoughness), 그 거칠기로 NoV = saturate(dot(VertexNormal, CameraVector))(UE `TangentToWorld[2]`)의 F90을 굽는다(SubstrateBakeF90ToReflectivity — 순서는 SE:1105–1109). metal = saturate((max3(F0) − 0.08)/0.32), baseColor = lerp(DiffuseAlbedo, F0, metal), metallic = metal, specular = saturate(max3(F0)/0.08), anisotropy = HasAnisotropy ? Anisotropy : 0(shading model이 DefaultLit·ClearCoat가 아니면 0 — SE:1305–1309), emissive = Emissive × Coverage, normal·tangent = 접은 기저(정규화). shading model 사슬(위가 우선): Profile → SubsurfaceProfile(opacity = RadiusScale — RadiusScale ≤ 0.1(UE SSSS_OPACITY_THRESHOLD_EPS)이면 사슬을 내려가지 않고 DefaultLit, SE:1218–1231), Wrap → Subsurface, TwoSidedWrap → TwoSidedFoliage(둘 다 subsurfaceColor = exp(−1/max(ε, SSSMFP·0.01)), opacity = 1 − abs(PhaseAnisotropy)), HasFuzz → Cloth(subsurfaceColor = FuzzColor, customData0 = FuzzAmount), HasHaze ∧ SimpleClearCoat → ClearCoat(customData0 = HazeWeight, customData1 = HazeRoughness), IsThin ∧ 반투명 블렌드 → ThinTranslucent(투과 색은 MS2d3 `ThinTranslucentMaterialOutput` 출력 — T = exp(−0.01/max(ε, MFP)), 고전 변환의 역 — 고전 ThinTranslucent는 반투명 전용이므로 불투명이면 UE Blendable처럼 DefaultLit), 그 밖 DefaultLit. 쓰지 않는 칸은 `DefaultSurfaceAttributes()` 값이다(사슬 쪽마다 같은 칸을 써야 Select가 되므로 기본값 상수로 채운다). Coverage는 내보낸 표면의 coverage 값이 되어 반투명 Opacity 진입점이 된다(MS2d1 규칙 — 표면 opacity 칸이 아니다).
- **기능 충돌 경고(10.3절).** 사슬 조건 둘 이상이 상수 참이면(예: fuzz와 SimpleClearCoat) 위 우선순위로 하나를 고르고 표면 기록 원인 노드 위치에 UnsupportedCapability 경고 "Surface combines features of several shading models; lower-priority features are ignored"를 낸다. 값으로 갈리는 조건은 픽셀마다 고르므로 경고하지 않는다.
- **흐르는 종류(MS2d2b).** 기록마다 하위 트리의 BSDF 종류 집합(UE MTV: Unlit·Slab·Hair·Eye·SLW·Toon·VFogCloud·UI·Decal·PostProcess·LightFunction)을 둔다. 고전 preset은 shading model이 static으로 Hair·Eye·SingleLayerWater·Unlit 하나면 그 종류, 그 밖은 Slab이다(UE MES:632–773). 연산 lowering이 허용 표로 검사하고, 허용되지 않는 종류만 UE 순서로 나열한다: "Substrate error: Operator <연산> cannot be used with the following data flowing through {Hair }."(UE 꼬리 "(asset: …)"는 진단 위치가 대신한다 — 연산 노드 위치 UnsupportedCapability). Decal이 연산에 들어가면 "Substrate Convert To Decal node must be the root of a parameter blending sub tree: no more Substrate operations can be applied a over its output.", SingleLayerWater면 "Substrate SingleLayerWater BSDF node cannot be used with parameter blending."다(UE 둘째 문구 "cannot be the root of a parameter blending sub tree"는 Rocks에서 생기지 않는다 — BSDF 하나는 섞지 않는다). 연산의 `useParameterBlending` 속성은 읽지 않는다(Blendable — 언제나 섞는다).
- **뿌리 내보내기(MS2d2b).** 뿌리 기록에 따라: Select면 두 쪽을 각각 내보내고(연산 아래이므로 고전 preset은 slab으로 바꾼다) 칸마다 고른다. 내보내기는 점별 함수이므로 UE의 BSDF 선택 뒤 내보내기와 결과가 같고 Hair·Eye가 섞여도 된다. Weight 아래가 Unlit 종류면 그 표면을 내보내고 emissive × w, coverage × w다. 그 밖의 연산·slab은 접어서 slab 하나를 내보낸다. 고전 preset이 뿌리에 바로 이어지면 MS2d1대로 칸을 그대로 쓴다.
- **연산 접기(MS2d2b).** 위 식대로 깊은 것부터 접는다. 섞기 전 입력 slab은 NoV = saturate(dot(그 slab의 노멀, CameraVector))로 F90을 굽는다(HLSLT:13597–13598). Horizontal·Add의 Profile 병합은 RadiusScale만 다룬다(Rocks는 profile id가 없다 — MPQ-SubsurfaceProfile): Horizontal은 lerp(Bg가 Profile이면 그 값 아니면 0, Fg도 같게, w), Add는 A가 Profile이면 A 값, 아니면 B 값이다(S:3076–3091 — Add에는 정리 규칙이 없다). Horizontal은 결과 RadiusScale이 0이면 None, Profile이 아니면 MFP가 모두 0일 때 None이다(S:2870–2950). 층 투과 평균의 무게는 UE처럼 0.33이다(dot(Tslab, 0.33) — S:3233). Vertical은 UE 식 그대로다(위층 굴절 NoV = UE `SubstrateComputeTransmittanceNoV`, 매질 = `CreateMediumFromBaseColorMFP(Top.DiffuseAlbedo, Top 계산 공간 MFP·0.01)`, Tslab = T(1 m, NoVt)·T(1 m, 1), 위층 albedo = `IsotropicMediumSlabPunctualDirectionalAlbedoALU`, 불투명이면 TmpMFP = Base.TmpMFP·L·Coverage = c_T + TOB, 반투명이면 UE 반투명 분기(MaxCoverage·Info2)와 계산 공간 재설정). Select는 slab 칸마다 고르고(연산 안), SelectValue > Threshold면 B다(같으면 A — UE `If`).
- **고전 preset → slab(MS2d2b, 연산 아래).** UE `SubstrateConvertLegacyMaterialDynamic`(SLC:153–524) 식이다. Metallic·Opacity·TransmittanceColor·ThinTranslucentSurfaceCoverage는 먼저 saturate(SLC static과 같다), AlphaComposite면 Opacity는 1이다(UE `SUBSTRATE_USE_PREMULTALPHA_OVERRIDE` — SLC:562, opacity는 Opacity 출력 핀이 맡는다). 고전 slab은 thin이 아니다(UE `CreateLegacySlab` bIsThinSurface false — SLC:85, 141). shading model이 상수면 그 모델 식, 값으로 갈리면 닿는 상수(MS2d1 집합 규칙)마다 식을 만들고 `model == k` Select로 고른다(픽셀마다 — UE Dynamic). 모델 식: DefaultLit = 금속도 slab(DiffuseAlbedo = bc(1 − m), F0 = lerp(0.08·spec, bc, m), F90 1, FuzzRoughness = 0.5 + 0.5·r); Subsurface = MFP = TransmittanceToMFP(SubSurfaceColor, 1 m)·100 ≥ 1e-5 cm, PhaseAnisotropy = 1 − Opacity, Wrap, 두께 100 cm(반투명이면 MFP 0); TwoSidedFoliage = 같은 식을 두께 0.01 cm로, TwoSidedWrap; SubsurfaceProfile = Opacity > 0.1이면 RadiusScale = Opacity·PhaseAnisotropy 0.93·Diffusion(→ Profile); ClearCoat = HazeWeight = ClearCoat, HazeRoughness = ClearCoatRoughness, SimpleClearCoat = ClearCoat > 0 ∨ ClearCoatNormal 연결; Cloth = F0 ×(1 − ClearCoat), FuzzAmount = ClearCoat, FuzzColor = SubSurfaceColor; ThinTranslucent = T = lerp(TransmittanceColor, 0, Opacity), MFP = TransmittanceToMFP(T, 0.0001 m)·100, F0 = lerp(0.08·spec, lerp(0.08·spec, bc, m), Opacity), DiffuseAlbedo = lerp(0, bc(1 − m), Opacity), anisotropy 0, SimpleVolume, Coverage = ThinTranslucentSurfaceCoverage; Unlit = 발광 slab(bc 0·spec 0·m 0·r 0). anisotropy는 DefaultLit·ClearCoat가 아니면 0이다. 반투명 블렌드면 Coverage = Opacity(ThinTranslucent 제외 — UE `SUBSTRATE_LEGACYCONVERT_OUTPUT_OPACITY`). 닿는 상수에 Hair·Eye·SingleLayerWater가 있으면 허용 표 오류다(UE는 slab 최악 경우로 받고 픽셀마다 전용 BSDF를 섞어 결과가 정해지지 않는다 — Rocks는 막는다, 편차).
- **ThinFilm(MS2d2c).** UE 비참조판 `F_ThinFilm`(ThinFilmBSDF.ush — Airy 합 세 항·감도 함수·XYZ→RGB)은 닫힌 식이므로 IR로 펼친다. 위의 "새 IR 연산 ShaderFunction"은 두지 않는다(펼친 식이 60개 남짓의 연산이고 hash-consing이 공통 부분을 한 번만 낸다 — 새 연산과 셰이더 파일을 늘리지 않는다). NoV = dot(Normal, CameraVector)(UE는 saturate하지 않고 NoV ≤ 0이면 반사 0). 연결된 Normal은 BSDF 노멀처럼 world로 바꿔 정규화한다(UE CompileWithDefaultNormalWS → TransformNormalFromRequestedBasisToWorld, HT:11521–11531).

**MS2d3 추가 출력.**
- **생성 함수.** custom 출력 노드마다 출력 번호 i(UE `GetNumOutputs`)별로 `float4 EvaluateMaterialCustomOutput_<이름><i>(in MaterialInputs c)`(픽셀) 또는 `(in MaterialVertexInputs c)`+`EvaluateMaterialCustomOutputPrevious_<이름><i>`(정점 빈도·이전 프레임 — FirstPersonOutput)을 낸다. 이름은 UE `GetFunctionName`에서 `Get` 접두를 뗀 Rocks 이름이다(예: BentNormal·ClearCoatBottomNormal·TangentOutput·ThinTranslucentMaterialOutput·SingleLayerWaterMaterialOutput·VolumetricAdvancedMaterialOutput·FirstPersonOutput·VirtualTextureOutput). 값은 float4로 맞춘다(짧으면 0을 붙인다). 존재 정의 `#define MATERIAL_CUSTOM_OUTPUT_<NAME> <출력 수>`·`#define MATERIAL_HAS_CUSTOM_OUTPUT_<NAME><i> 1`(UE `NUM_MATERIAL_OUTPUTS_`·`HAVE_`)를 낸다. 7.3절 표의 한 줄을 이 규칙으로 고친다.
- **입력.** 기본값 있는 입력은 UE 기본값(조사표 5.1), 기본값 없는 입력은 연결이 없으면 그 번호의 함수를 내지 않는다(UE INDEX_NONE — SubsurfaceMedium·MotionVectorWorldOffset·TemporalResponsiveness), BentNormal·ClearCoatNormal·TangentOutput은 연결이 없으면 "Input missing"(UE MaterialExpressions.cpp:20262–20344). 노멀·tangent 출력은 tangent 공간 그대로 낸다(UE처럼 소비자가 바꾼다 — MT:4913–4925).
- **하나만.** 같은 종류의 출력 노드가 둘이면 "The material can contain only one <이름> node"(UE HT:876–961 — MaterialCache만 여럿 가능).
- **IR.** 진입점은 `IrEntry::CustomOutput`이고 slot은 "<이름><i>"(정적 원문 표)다. 정점 빈도 출력은 `IrEntry::CustomOutputVertex`(새)·이전 프레임은 정점 문맥 둘에서 번역한다. 번역 결과 `customOutputs`(이름 목록 — 8.3절 거르기)에 담는다.
- 입력 노드처럼 보이는 VolumetricAdvancedInput·CloudSampleAttribute·VolumetricCloudEmptySpaceSkippingInput은 문맥 값(이미 표에 있다)을 읽는 lowering이다. NeuralNetworkInput·Output은 UE 신경망 후처리(`neural` 기능 — profile은 TODO MPQ-NeuralProfile, 19.9절)로 custom 출력 GetNeuralInput과 문맥 값이다. MaterialCacheOutput은 TODO(MPQ-VirtualTexture).

- **번역.** 출력 노드의 문맥 번역이 끝난 뒤 custom 출력 노드마다(비활성 노드는 건너뛴다) 그 입력에서 닿는 노드를 의존 후위 순서로 번역하고(출력 노드와 같은 계획 규칙), 번호마다 결과를 낸다. 진입점은 픽셀이면 `IrEntry::CustomOutput`, 정점이면 `IrEntry::CustomOutputVertex`(9)와 `IrEntry::CustomOutputVertexPrevious`(10 — 이전 정점 문맥에서 다시 번역, UE `NeedsPreviousFrameEvaluation`)다. slot은 "<이름><번호>"(표의 정적 원문)다. 같은 종류의 노드가 둘이면 둘째부터 그 노드 위치에 UnsupportedCapability "The material can contain only one <표시 이름> node"(UE HT:876–961)이고 번역하지 않는다. 출력 노드처럼 그래프의 뿌리이므로 `MaterialCacheOutput`(TODO `MPQ-VirtualTexture`)은 있으면 그 노드 위치에 PrerequisiteMissing을 낸다(Pending 자리 값이 결과에 닿는 길이 없다).
- **RVT 범위.** `RuntimeVirtualTextureOutput`의 입력은 RVT 범위에서 번역한다: 픽셀 문맥이지만 노드 결과 캐시를 따로 둔다(UE `PushRuntimeVirtualTextureOutput` — 같은 노드가 범위 안팎에서 다른 값을 낸다). 범위 안에서 `RuntimeVirtualTexturePassSwitch`는 VirtualTextureOutput 입력, `RuntimeVirtualTextureCustomData`는 문맥 값이다(밖은 Default·0 — 6.9절 그대로). 범위에서 다시 번역한 노드의 같은 진단은 한 번만 남는다(진단 목록이 같은 위치·코드·문구를 거른다). 연결된 입력은 `MaterialTranslation.virtualTextureOutputMask`(UE `RuntimeVirtualTextureOutputAttributeMask` — ERuntimeVirtualTextureAttributeType 비트 BaseColor 0·Normal 1·Roughness 2·Specular 3·Mask 4·Mask4 5·WorldHeight 6·Displacement 7, Opacity는 비트가 없다 — MaterialExpressions.cpp:3054–3115)에 담는다.
- **표면이 주는 출력.** 그 종류의 노드가 없으면 뿌리 표면이 준다(UE 고전 변환이 같은 함수를 쓴다 — 노드가 있으면 노드가 이긴다, UE `CompileMaterialAttributesCustomOutputs`의 노드 우선): 고전 preset의 ClearCoatNormal(연결된 때)·SimpleClearCoat BottomNormal·Eye IrisNormal → `ClearCoatBottomNormal`, 고전 preset의 CustomTangent(연결된 때) → `TangentOutput`, ThinTranslucent shading model 고전 preset의 TransmittanceColor·ThinTranslucentSurfaceCoverage와 slab IsThin(T = exp(−0.01/max(ε, MFP)), coverage 1) → `ThinTranslucentMaterialOutput`, SingleLayerWater shading model 고전 preset의 물 계수와 SingleLayerWater BSDF(Scattering = WaterAlbedo·WaterExtinction, Absorption = WaterExtinction − Scattering, PhaseG, ColorScaleBehindWater) → `SingleLayerWaterMaterialOutput`. 연산 아래의 추가 칸은 버린다(접은 closure 하나 — UE Blendable도 haziness 아래 노멀 하나만 남는다). 노멀·tangent 출력은 노드든 표면이든 입력 원값(머티리얼 노멀 공간 — `tangentSpaceNormal`이면 tangent 공간)이다(UE처럼 소비자가 `MATERIAL_TANGENTSPACENORMAL`을 보고 바꾼다 — MT:4913–4925).
- **정의.** 생성 원문은 출력 종류마다 `#define MATERIAL_CUSTOM_OUTPUT_<NAME> <출력 수>`(NAME은 이름의 대문자 — UE `NUM_MATERIAL_OUTPUTS_`)와 결과가 있는 번호마다 `#define MATERIAL_HAS_CUSTOM_OUTPUT_<NAME><i> 1`(UE `HAVE_`)을 낸다. 노드 속성이 정하는 정의는 IR 모듈의 정의 목록(`IrDefine` — 이름·값, IR hash에 넣는다)으로 낸다: VolumetricAdvancedOutput → `MATERIAL_VOLUMETRIC_ADVANCED` 1, `…_PHASE_PERSAMPLE`(perSamplePhaseEvaluation ∧ PhaseG·PhaseG2·PhaseBlend 중 연결) 또는 `…_PHASE_PERPIXEL`, `…_GRAYSCALE_MATERIAL`·`…_RAYMARCH_VOLUME_SHADOW`·`…_CLAMP_MULTISCATTERING_CONTRIBUTION`·`…_MULTISCATTERING_OCTAVE_COUNT`·`…_CONSERVATIVE_DENSITY`(입력 연결)·`…_OVERRIDE_AMBIENT_OCCLUSION`(출력 AO 연결 또는 VolumetricFogCloud AO 핀 연결 — UE bBSDFWritesAmbientOcclusion, MES:1619)·`…_GROUND_CONTRIBUTION`(UE HT:2542–2561, 14965–14985), VolumetricCloudEmptySpaceSkippingOutput → `MATERIAL_VOLUMETRIC_CLOUD_EMPTY_SPACE_SKIPPING_OUTPUT` 1. 둘은 Volume 영역에서만 낸다(UE HT:14963). 번역 결과 `MaterialTranslation.customOutputs`는 결과가 있는 출력 이름(표 순서)이다(8.3절 거르기).
- **생성 함수.** 픽셀: `float4 EvaluateMaterialCustomOutput_<이름><i>(in MaterialInputs c)`, 정점: `float4 EvaluateMaterialCustomOutput_<이름><i>(in MaterialVertexInputs c)`와 `float4 EvaluateMaterialCustomOutputPrevious_<이름><i>(in MaterialVertexInputs c)`다. 결과가 있는 번호만 낸다(7.3절 예외 — pass는 존재 정의로 고른다).
- **순환 검사.** `ClearCoatBottomNormal`·`TangentOutput`·`BentNormal` 결과도 대표 노멀 순환 검사 뿌리다(19.3.3절).
- **신경망.** `NeuralNetworkInput`의 Coordinates는 연결되면 그 값(TextureIndex면 −1과 뒤 세 성분 — UE `AppendVector(-1, yzw)`), 아니면 (TextureIndex면 −1, 아니면 0, 0, ViewportUv)다. `NeuralNetworkOutput`은 문맥 값 `NeuralTextureOutput(uv)`(TextureIndex — Coordinates 없으면 ViewportUv)·`NeuralBufferOutput(index)`(BufferIndex — 없으면 (0, 0, ViewportUv))이고 PostProcess 영역이 아니면 V6 "NNE Output Node are only available on post process material."(UE HT:12770–12806)다. 문맥 값 둘은 표 끝에 더한다(기능 `neural`).
- **입력 노드.** `VolumetricAdvancedInput`은 VolumeSampleConservativeDensity(0: float3로, 1: 그대로), `CloudSampleAttribute`는 CloudSample 넷, `VolumetricCloudEmptySpaceSkippingInput`은 CloudEmptySpaceSkipping 둘을 낸다(UE ExternalCode 노드).

**편차·한계(요약).** UI 표면의 Modulate·AlphaHoldout 변형은 pass 블렌드가 맡는다. Vertical의 위층 albedo는 ALU 근사다(UE 데스크톱은 4D LUT). Select tangent 결함은 고친다. MFP만 있는 SSS(Diffusion)는 UE Blendable처럼 DefaultLit이다. slab IsThin은 반투명이면 ThinTranslucent로 낸다(UE Blendable DefaultLit). 대표 노멀 순환 규칙은 UE보다 넓다.
