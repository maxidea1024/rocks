# 셰이더 라이브러리 — 4.15 반투명·굴절(A15)

[4장 목차](README.ko.md)

### 4.15 반투명·굴절(A15)

**역할.** 투명 메시 pass(`Translucent` — 같은 조명 함수, 자기 셰이더 안 안개 적용), 블렌드 모드별 출력(`Translucent`·`Additive`·`Modulate`·`AlphaComposite`), 분리 투명(`TranslucentAfterDof`·`TranslucentAfterMotionBlur`) 합성과 저해상도 투명 업샘플, distortion(굴절 offset 누적 → SceneColor 복사본에 적용).

**UE 파일(8).** `ComposeSeparateTranslucency.usf`, `SeparateTranslucency.ush`, `TranslucencyUpsampling.usf`, `DistortAccumulateVS.usf`, `DistortAccumulatePS.usf`, `DistortApplyScreenPS.usf`, `DistortFiltering.usf`, `DistortionCommon.ush`. (반투명 조명 볼륨 `TranslucencyVolume*`·`TranslucentLight*`·`TranslucentShadowDepthShaders`는 A25 후속, OIT는 A35 후속, Lumen 앞면 투명은 A27.)

**UE 구조 메모.** 투명 메시 셰이더 자체는 UE에서도 base pass 원문(`BasePassPixelShader.usf`)의 투명 분기다. Rocks는 `Translucency/TranslucentPass.rsf`로 나눈다.

**의존.** A05·A07 `MeshPassCommon`, A09 조명 함수, A10 그림자, A11 sky light·반사, A16 안개 함수, A18 복사. 렌더러: RN 10.2절, 6.2절 F14, 11.2절 PC2·PC5, RS5. 머티리얼: MS MS7(SF2 블렌드 모드).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Translucency/TranslucentPass.rsf` | `Translucent` 메시 pass: 표면 평가 → 조명 함수 → 안개(height fog·aerial perspective) → 블렌드 모드별 출력(premultiplied 규칙 하나로 통일, 블렌드 상태는 C++ 프리셋) | SL7 |
| `Translucency/BlendModeOutput.rsh` | 블렌드 모드 → (색, 알파) 출력 규칙, `Modulate`의 곱 출력, 노출 적용 순서 | SL7 |
| `Translucency/ComposeTranslucency.rsf` | 분리 투명 RT 합성(PC2·PC5), 저해상도 투명의 깊이 인식 업샘플(nearest-depth) | SL7 |
| `Translucency/DistortionAccumulate.rsf` | 굴절 머티리얼의 화면 offset 누적(`Distortion` 메시 pass) | SL7 |
| `Translucency/DistortionApply.rsf` | SceneColor 복사본 + offset 버퍼 → 합성, 가장자리 처리 | SL7 |

**단계.** SL7(RN RS5).

**근거 문헌.** Porter, Duff, *Compositing Digital Images*, SIGGRAPH 1984(premultiplied 알파); Wronski, *Volumetric Fog*, SIGGRAPH 2014 Advances(투명의 안개 적용 순서, A16·A25 참조); Sousa, *Generic Refraction Simulation*, GPU Gems 2 2005; Jansen, Bavoil, *Fourier Opacity Mapping*, I3D 2010(투명 그림자 — 후속 참고).
