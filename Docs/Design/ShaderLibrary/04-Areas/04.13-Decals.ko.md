# 셰이더 라이브러리 — 4.13 데칼(A13)

[4장 목차](README.ko.md)

### 4.13 데칼(A13)

**역할.** 투영 decal(상자 볼륨)과 mesh decal을 그리는 pass와 decal 머티리얼 출력 규칙: Deferred는 GBuffer에 블렌드(F10), Forward+는 base pass 전에 DBuffer(색·법선·roughness 세 장)에 그려 base pass가 읽는다(F8a). DBuffer 법선 재투영, 각도 fade, 거리 fade, 정렬 순서.

**UE 파일(5).** `DeferredDecal.usf`, `DecalCommon.ush`, `DBufferDecalShared.ush`, `DBufferNormalReprojection.ush`, `MeshDecals.usf`.

**의존.** A05(머티리얼 영역 `DeferredDecal` — MS MS7), A06(깊이 → 위치 복원), A07(GBuffer 인코딩 — 블렌드 가능한 채널만), A02(법선 인코딩). 렌더러: RN 6.2절 F8a·F10, RS7. 컴포넌트: `DecalComponent`(CC CM8).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Decal/DecalCommon.rsh` | decal 공간 변환(화면 위치 → decal 상자 local), 상자 밖 clip, 각도·거리 fade, 수신 표면 법선 | SL9 |
| `Decal/DeferredDecalPass.rsf` | 상자 볼륨 decal: 앞면·뒷면(카메라가 안에 있을 때) 그리기, GBuffer 블렌드 출력(base color·법선·roughness·emissive 선택 쓰기) | SL9 |
| `Decal/DBufferDecalPass.rsf` | Forward+ DBuffer 쓰기(색+알파, 법선+알파, roughness·metallic·specular+알파), 법선 재투영 | SL9 |
| `Decal/DBufferRead.rsh` | base pass가 DBuffer를 읽어 `SurfaceAttributes`에 섞는 함수(퍼뮤테이션 DBuffer {0,1}, RN 14.3절) | SL9 |
| `Decal/MeshDecalPass.rsf` | mesh decal(메시 표면을 따라 그리는 decal 머티리얼) — 같은 출력 규칙 | SL9 |

**단계.** SL9(RN RS7).

**근거 문헌.** Persson, *Volume Decals*, GPU Pro 2 2011; Kim, *Decals in Deferred Shading*(Splinter Cell: Conviction), GDC 2009; Sousa, Kasyan, Schulz, *Secrets of CryENGINE 3 Graphics Technology*, SIGGRAPH 2011 Talks(deferred decal).
