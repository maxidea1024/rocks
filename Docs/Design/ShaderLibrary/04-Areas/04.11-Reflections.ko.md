### 4.11 반사·sky light·캡처·SSR(A11)

**역할.** 환경 cube 표본(roughness → mip), 반사 capture 배열 조회·영향 범위(상자·구·평면 모양)·parallax 보정·섞기, capture·하늘 cube 사전 필터(GGX)와 SH 조도 투영, sky light 확산(SH)·반사(cube) 평가, 간접광 합성(F12), planar reflection, scene capture 출력 변환, 화면 공간 반사(SSR).

**UE 파일(19).** `ReflectionEnvironmentShaders.usf`, `ReflectionEnvironmentShared.ush`, `ReflectionEnvironmentComposite.ush`, `ReflectionEnvironmentPixelShader.usf`, `CubemapCommon.ush`, `SkyLightingShared.ush`, `SkyLightingDiffuseShared.ush`, `AmbientCubemapComposite.usf`, `DiffuseIndirectComposite.usf`, `PlanarReflectionShaders.usf`, `PlanarReflectionShared.ush`, `SceneCapturePixelShader.usf`, `DefaultSSRTiles.usf`, `ScreenSpaceReflectionTileCommons.ush`, `SSRT/SSRTReflections.usf`·`SSRTRayCast.ush`·`SSRTTileClassification.usf`·`SSRTTileClassificationBuffer.ush`·`SSRTPrevFrameReduction.usf`. (`SSRT/SSRTDiffuseIndirect.usf`는 SSGI deprecated로 제외 — 1.4절.)

**의존.** A02(SH·중요도 표본·저불일치), A04(환경 BRDF·에너지 보존), A06(장면 텍스처·HZB 추적), A07(GBuffer·보조 출력), A12(AO 곱), A18(cube 밉·복사). 렌더러: RN 6.2절 F12, 7.4절(반사 capture cube array 자리), RS1(sky light 상수)·RS7(capture·sky light)·RS10(SSR·planar). 내장 자원: 검은 cube·cube array(RB 11.1절, capture 알파 규칙).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Reflection/CubemapSampling.rsh` | roughness → mip 사상(capture mip 수 기준), Z-up world 방향 → cube 표본 방향 규약(3.4절), 이음매 없는 표본 | SL3 |
| `Reflection/SkyLighting.rsh` | sky light 확산(SH 3차 조도, 법선·bent normal), 반사(cube, 환경 BRDF), AO·specular occlusion 곱 | SL3(상수 SH)·SL9(capture) |
| `Reflection/ReflectionCaptures.rsh` | capture 배열 조회(cube array index), 상자·구·평면 모양 영향 가중과 parallax 보정, 거리 순 섞기, capture 알파(덮는 비율)와 sky 보충 | SL9 |
| `Reflection/FilterEnvironmentCube.rsf` | capture·하늘 cube: 면 다운샘플 → mip별 GGX 사전 필터(filtered importance sampling) → SH 조도 투영(compute 축소) | SL9 |
| `Reflection/IndirectComposite.rsf` | 간접광 합성 F12: 반사 capture·sky·(후속 GI·SSR 결과) + AO를 SceneColor에 별도 기여로 가산(이중 가산 금지, RN 6.2절) — Deferred는 GBuffer, Forward+는 보조 출력 기반 | SL9 |
| `Reflection/SceneCaptureOutput.rsf` | scene capture 결과 변환(HDR SceneColor·노출 적용 LDR·장면 깊이·world 법선·base color 등 출력 종류), cube capture 면 배치 | SL9 |
| `Reflection/PlanarReflection.rsf`·`.rsh` | 반사 평면 view 결과 사전 흐림(roughness 대응), 표본 때 법선 왜곡·평면 거리 fade | SL10(RN RS10) |
| `Reflection/ScreenSpaceReflections.rsf`·`.rsh` | 타일 분류(반사 필요 픽셀만), HZB 광선 진행(A06 `HzbScreenTrace`), roughness별 원뿔·광선 수, 이전 프레임 색 축소 pyramid, 시간 누적·해상, 화면 가장자리·두께 fade | SL10 |

**들이지 않는 것(지금).** ambient cubemap 후처리 설정(`AmbientCubemapComposite.usf`) — sky light와 겹치는 옛 후처리 조명으로, PostProcessVolume 설정 목록(EIP 26.2절)이 필요하다고 정할 때 후속.

**단계.** SL3(cube 표본·sky light 상수), SL9(RN RS7: capture·필터·sky light capture·간접 합성·scene capture), SL10(RN RS10: SSR·planar).

**근거 문헌.** Karis 2013(split-sum·사전 필터, A04 참조); Lagarde, Zanuttini, *Local Image-based Lighting With Parallax-corrected Cubemap*, SIGGRAPH 2012 Talk; Křivánek, Colbert, *Real-time Shading with Filtered Importance Sampling*, EGSR 2008; Ramamoorthi, Hanrahan 2001(SH 조도); McGuire, Mara, *Efficient GPU Screen-Space Ray Tracing*, JCGT 2014; Uludag, *Hi-Z Screen-Space Cone-Traced Reflections*, GPU Pro 5 2014; Stachowiak, *Stochastic Screen-Space Reflections*, SIGGRAPH 2015 Advances; Lagarde, de Rousiers 2014(specular occlusion).
