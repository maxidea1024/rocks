# 셰이더 라이브러리 — 4.16 하늘 대기·높이 포그(A16)

[4장 목차](README.ko.md)

### 4.16 하늘 대기·높이 포그(A16)

**역할.** 물리 기반 하늘 대기(Rayleigh·Mie·오존 흡수, 다중 산란 근사)의 LUT 생성(투과율·다중 산란·하늘 view·aerial perspective 볼륨)과 전체 화면 하늘 그리기, directional 광원의 대기 투과율, 지수 높이 안개(두 층, 방향성 산란 lobe, 시작 거리·끝 거리), 참여 매질 공통 함수(위상 함수).

**UE 파일(6).** `SkyAtmosphere.usf`, `SkyAtmosphereCommon.ush`, `HeightFogCommon.ush`, `HeightFogPixelShader.usf`, `HeightFogVertexShader.usf`, `ParticipatingMediaCommon.ush`. (볼륨 안개·볼륨 구름·지역 안개 볼륨·광선 축은 A25 후속, `MobileFog.usf`는 제외.)

**의존.** A02(적분 표본), A03(색), A06(깊이 → 거리), A08(대기 광원 = directional 기록). 쓰는 곳: A15(투명의 안개·aerial perspective), A11(하늘 capture — sky light real-time capture), A09(directional 광원 색에 대기 투과율). 렌더러: RN 10.2절(결정 RN8 — 두 경로 모두 전체 화면 pass), 6.2절 F3·F13, RS5. 컴포넌트: `SkyAtmosphereComponent`·`HeightFogComponent`(CC CM8).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Atmosphere/ParticipatingMedia.rsh` | Rayleigh·Henyey–Greenstein·Cornette–Shanks·두 lobe 위상 함수, 소광·산란 계수 단위(1/cm 대신 1/km 입력 → 내부 변환 규칙 고정) | SL7 |
| `Atmosphere/AtmosphereModel.rsh` | 행성 반지름·대기 높이(UE 파라미터 의미와 같게), 밀도 분포(지수·층), world(cm, Z-up) ↔ 행성 좌표(km) 변환, 광선–구 교차 | SL7 |
| `Atmosphere/BuildAtmosphereLuts.rsf` | 투과율 LUT, 다중 산란 LUT(2차 이상 등방 근사), 하늘 view LUT(위도·경도 매핑), aerial perspective 카메라 볼륨 LUT | SL7 |
| `Atmosphere/SkyAtmospherePass.rsf` | 원평면 깊이 픽셀(reversed-Z 0)에 하늘 그리기, 태양 원반, 그 밖 픽셀에 aerial perspective 적용 | SL7 |
| `Atmosphere/HeightFog.rsh` | 두 층 지수 높이 안개 해석 적분, 방향성 산란, 시작·끝 거리, 최대 불투명도, 하늘 cube 색 사용 선택 | SL7 |
| `Atmosphere/HeightFogPass.rsf` | 전체 화면 안개 합성(깊이 → 거리, SceneColor 혼합) | SL7 |
| `Shared/EnvironmentFlags.h` | 하늘·안개·대기 사용 플래그(3.3절) | SL7 |

**들이지 않는 것.** 옛 볼륨 UV 함수(`HeightFogCommon.ush`의 `ComputeVolumeUV_DEPRECATED`), 화면 공간 안개 산란·분리 합성(`FogScreenSpaceScattering`·`FogSeparateComposition` — A25 후속).

**단계.** SL7(RN RS5).

**근거 문헌.** Hillaire, *A Scalable and Production Ready Sky and Atmosphere Rendering Technique*, EGSR 2020(CGF); Bruneton, Neyret, *Precomputed Atmospheric Scattering*, EGSR 2008; Nishita, Sirai, Tadamura, Nakamae, *Display of the Earth Taking into Account Atmospheric Scattering*, SIGGRAPH 1993; Wenzel, *Real-time Atmospheric Effects in Games Revisited*, GDC 2007; Quílez, *Better Fog*, 2010(지수 높이 안개 해석 적분); Cornette, Shanks, *Physically Reasonable Analytic Expression for the Single-Scattering Phase Function*, Applied Optics 1992; Henyey, Greenstein, *Diffuse Radiation in the Galaxy*, ApJ 1941.
