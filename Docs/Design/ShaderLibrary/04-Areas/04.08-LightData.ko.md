# 셰이더 라이브러리 — 4.8 광원 데이터·light grid·광원 함수(A08)

[4장 목차](README.ko.md)

### 4.8 광원 데이터·light grid·광원 함수(A08)

**역할.** 광원 기록(위치·광량·방향·spot 각·종류·그림자·IES·광원 함수 index·source 크기)의 GPU 배치와 해독, 거리 감쇠·spot 감쇠, light grid 생성(compute)과 조회, IES 프로필 atlas, 사각 광원 텍스처 atlas, 광원 함수(머티리얼 영역 `LightFunction`) atlas.

**UE 파일(17).** `LightData.ush`, `LightDataUniforms.ush`, `LightShaderParameters.ush`, `LightGridCommon.ush`, `LightGridInjection.usf`, `IESLightProfilesCommon.ush`, `IESAtlas.usf`, `RectLightAtlas.usf`, `LightFunctionCommon.ush`, `LightFunctionPixelShader.usf`, `LightFunctionVertexShader.usf`, `LightFunctionAtlas/LightFunctionAtlasCommon.usf`·`LightFunctionAtlasRender.usf`, `Shared/LightDefinitions.h`·`LightGridDefinitions.h`·`LightSceneData.h`·`LightViewData.h`.

**의존.** A01·A02·A06(view Z·HZB). 쓰는 곳: A09(직접광), A15(투명 조명), A25(볼륨 안개 — 후속). 렌더러: RN 8.1절(light grid 전체 규칙: 64 px·Z 32단·로그 분포·두 단계 CS·넘침 보수 대체·typed buffer `R32Uint`·`RGBA32Float`·원소 상한·빈 grid), RN 6.2절 F6, RS1·RS9. 내장 자원: 빈 light grid(RB 11.1절).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Lighting/LightRecord.rsh` | 광원 기록 해독(typed buffer `RGBA32Float` 6–8 texel, RN 8.1절), 광원 종류 번호(`Shared/LightRecordLayout.h`), directional 목록 상수 | SL3 |
| `Lighting/LightAttenuation.rsh` | 역제곱 + 창 함수 거리 감쇠(반경에서 0), 옛 지수 감쇠는 두지 않는다, spot 원뿔 감쇠(내·외각), source radius 반영 거리 | SL3 |
| `Lighting/LightGridLookup.rsh` | 화면 위치 + view Z → 셀(Z 로그 분포, 좌표 clamp), 셀 머리(시작·개수)와 index 순회, 넘침 셀은 가시 local 광원 전체 순회 | SL3 |
| `Lighting/BuildLightGrid.rsf` | 두 단계 CS: (1) 셀 frustum × 광원 bounds(구·원뿔, rect는 구) 판정과 개수, HZB로 셀 깊이 좁히기 (2) prefix sum(A21)으로 시작 위치 → index 쓰기, 넘침 표지·계수 | SL3 |
| `Lighting/IesProfile.rsh`·`BuildIesAtlas.rsf` | IES 프로필 → 1D·2D atlas 행, 방향 → 표본 좌표(광원 좌표계는 UE와 같게) | SL10(RN RS9) |
| `Lighting/RectLightTextureAtlas.rsf` | 사각 광원 텍스처 atlas 채우기와 mip(LTC 적분이 roughness별 mip을 읽는다) | SL10 |
| `Lighting/LightFunctionAtlas.rsf`·`.rsh` | 광원 함수 머티리얼을 atlas 타일에 굽고(광원 공간 투영), 조명 함수가 표본한다(RN 14.3절 퍼뮤테이션 "광원 함수·IES atlas") | SL10 |
| `Shared/LightRecordLayout.h`·`LightGridLayout.h` | 3.3절 | SL3 |

**들이지 않는 것.** 광원 함수를 화면 공간 pass로 그리는 옛 방식(`LightFunctionVertexShader.usf`·`LightFunctionPixelShader.usf`의 deferred 광원별 투영) — Rocks는 광원별 deferred pass가 없으므로(RN 결정 RN1) atlas 방식 하나만 둔다.

**단계.** SL3(RN RS1: 광원 기록·감쇠·grid), SL10(RN RS9: IES·rect atlas·광원 함수).

**근거 문헌.** Olsson, Billeter, Assarsson, *Clustered Deferred and Forward Shading*, HPG 2012; Harada, McKee, Yang, *Forward+: Bringing Deferred Lighting to the Next Level*, Eurographics 2012 Short; Persson, Olsson, *Practical Clustered Shading*, SIGGRAPH 2013 Course; Karis 2013(창 함수 감쇠, A04 참조); IES LM-63-2019(광도 데이터 파일 형식); Lagarde, de Rousiers 2014(광량 단위 환산, A04 참조).
