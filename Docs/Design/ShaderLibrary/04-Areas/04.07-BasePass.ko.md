[4장 목차](README.ko.md)

### 4.7 깊이·velocity·베이스 패스·GBuffer(A07)

**역할.** 메시 pass(RN 14.3절 `MeshPass`)의 공통 정점·픽셀 틀, depth prepass·velocity, Forward+ 불투명 base pass, Deferred GBuffer 쓰기, GBuffer 인코딩·해독.

**UE 파일(15).** `DepthOnlyVertexShader.usf`, `DepthOnlyPixelShader.usf`, `PositionOnlyDepthVertexShader.usf`, `VelocityShader.usf`, `VelocityCommon.ush`, `VelocityUpdate.usf`, `BasePassVertexShader.usf`, `BasePassVertexCommon.ush`, `BasePassPixelShader.usf`, `BasePassCommon.ush`, `BasePassCommonFunctions.ush`, `GBufferHelpers.ush`, `DeferredShadingCommon.ush`, `AnisotropyPassShader.usf`, `FirstPersonSelfShadow.usf`.

**UE 구조 메모.** `BasePassPixelShader.usf`는 Forward 조명·Deferred GBuffer·반투명 조명·Substrate 경로를 정의 하나로 모두 가진 큰 파일이다. `DeferredShadingCommon.ush`의 GBuffer 인코딩 함수 가운데 고전 경로 함수는 5.7 deprecated이지만, Blendable GBuffer가 쓰는 배치 자체는 현재 경로다(RN 머리말 "Legacy GBuffer layout 함수" 설명, RN 7.1절).

**Rocks 차이.** pass마다 엔트리 파일을 나눈다(Forward+ 불투명과 GBuffer 쓰기를 한 파일에 섞지 않는다). 조명 평가는 A09 `Lighting/ForwardLighting.rsh`를, 머티리얼 평가는 생성 파일 함수를 부른다. 경로 정의 `RENDER_PATH_DEFERRED`·`RENDER_PATH_FORWARD_PLUS`(RN 14.3절)를 쓴다.

**의존.** A05(머티리얼 틀·정점 입력), A06(view·GPU Scene), A02(인코딩), A04(셰이딩 파라미터), A09(Forward+ 조명), A10(그림자 표본), A11(sky light·반사), A13(DBuffer 읽기), A14(정적 조명). 렌더러: RN 6.2절 F4·F9, 7.1–7.2절, 8.2–8.4절, RS0·RS1·RS2.

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `BasePass/MeshPassCommon.rsh` | 메시 pass 공통: 정점 입력 → `EvaluateMaterialVertex`(+이전) → clip 위치(jitter 포함·미포함 둘), 보간 값 묶기, 픽셀 쪽 `MaterialInputs` 구성(앞면 여부 — 음수 행렬식 반영), masked clip, PDO `SV_Depth` | SL2 |
| `BasePass/DepthPasses.rsf` | `Depth`·`DepthVelocity`·`DepthAux`(보조 법선·roughness `RGB10A2Unorm`)·`CustomDepth`(custom depth·stencil 값 — `PrimitiveComponent` 렌더 플래그, 후처리 머티리얼 mask·선택 외곽선) 엔트리. 위치만 쓰는 빠른 VS 변형(머티리얼 WPO 없음) | SL2(Depth·DepthVelocity)·SL8(CustomDepth)·SL10(DepthAux) |
| `BasePass/VelocityEncoding.rsh` | velocity 계산(현재 표본 → 이전 위치, jitter 제거)과 `RG16Float` 부호화·정지 물체 표지(RN 7.1·11.2절) | SL2 |
| `BasePass/VelocityPass.rsf` | 별도 `Velocity` pass(MSAA view 등) | SL2 |
| `BasePass/ForwardOpaquePass.rsf` | Forward+ 불투명 base pass: 표면 평가 → `ForwardLighting`(직접광·그림자·sky·반사·정적 조명·DBuffer) → SceneColor(+ 보조 출력). RS0은 `Unlit`·emissive만 | SL2(Unlit)·SL3(DefaultLit) |
| `BasePass/GBufferEncoding.rsh` | GBuffer A(법선 `RGB10A2Unorm`)·B(metallic·specular·roughness·shading model 4 bit)·C(base color sRGB·AO)·D(custom data)·E(정적 그림자 인자) 인코딩·해독, profile {기본·+D·+E·+D+E}(RN 7.1절, 결정 RN3·RN4) | SL4 |
| `BasePass/GBufferPass.rsf` | Deferred base pass: GBuffer 쓰기 + emissive·정적 간접광 → SceneColor | SL4 |
| `Shared/SurfaceEnums.h` | shading model·블렌드 모드·영역 번호표(3.3절) | SL2 |

**들이지 않는 것(지금).** `AnisotropyPassShader.usf`(GBuffer 이방성 출력 — RN 14.1절 `tangent`·`anisotropy`가 후속), `FirstPersonSelfShadow.usf`(1인칭 무기 자기 그림자 — 1인칭 렌더링 기능과 함께 후속), `PositionOnlyDepthVertexShader.usf`는 따로 두지 않고 `DepthPasses.rsf`의 빠른 VS 변형으로 흡수한다.

**단계.** SL2(RN RS0: 메시 공통·depth·velocity·Unlit base), SL3(RN RS1: DefaultLit Forward+), SL4(RN RS2: GBuffer), SL10(RN RS10: DepthAux).

**근거 문헌.** Cigolle 외 2014(법선 인코딩, A02 참조); Valient, *Deferred Rendering in Killzone 2*, Develop 2007; Kaplanyan, *CryENGINE 3: Reaching the Speed of Light*, SIGGRAPH 2010 Advances(best-fit 법선); Karis, *High Quality Temporal Supersampling*, SIGGRAPH 2014 Advances(velocity와 jitter).
