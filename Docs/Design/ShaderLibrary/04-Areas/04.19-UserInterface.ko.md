# 셰이더 라이브러리 — 4.19 2D·UI·단순 요소(A19)

[4장 목차](README.ko.md)

### 4.19 2D·UI·단순 요소(A19)

**역할.** UI 툴킷 그리기(UI UT2 `UiRender`)의 셰이더: 사각형·둥근 사각형(SDF)·테두리·선·그라디언트·이미지 brush·9-slice, 글리프(회색조·컬러·SDF·MSDF atlas), stencil·사각형 clip, 회전 render transform, 감마·HDR UI 합성, 색각 이상 보정 후처리, UI 흐림 후처리. 그리고 단순 요소(2D 선·삼각형·텍스처 미리보기 — 편집기 미리보기와 hit proxy 출력).

**UE 파일(13).** `SlateVertexShader.usf`, `SlateElementPixelShader.usf`, `SlateShaderCommon.ush`, `SlateMaskingShader.usf`, `SlatePostProcessPixelShader.usf`, `SlatePostProcessColorDeficiencyPixelShader.usf`, `CompositeUIPixelShader.usf`, `SimpleElementVertexShader.usf`, `SimpleElementPixelShader.usf`, `SimpleElementHitProxyPixelShader.usf`, `SimpleElementColorChannelMaskPixelShader.usf`, `SimpleElementTexture2DPreviewPixelShader.usf`, `SimpleElementVolumeTexturePreviewPixelShader.usf`. (단독 렌더러 `StandaloneRenderer/*`는 제외 — 1.4절.)

**의존.** A01·A02·A03(감마·sRGB·색각 이상), A18(전체 화면·복사). UI 툴킷 UT2(그리기 목록·atlas·render target·viewport 합성, EIP 21.4절), TextLayout(글리프 cache·SDF 생성은 CPU — msdfgen adapter). 컴포넌트: `WidgetComponent`(CC CM17 — UI를 render target에 그린 뒤 world 사각형 머티리얼로 표시), `TextRenderComponent`(CC CM5 — 글리프 atlas 표본 함수를 머티리얼이 공유).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Ui/UiCommon.rsh` | UI 정점 형식(위치·UV·색·brush 파라미터), 화면 → clip, render transform, 블렌드 색 공간 규칙(UE UI와 같은 공간에서 블렌드한다 — 정확한 규칙은 UT2 착수 때 UE 5.8에서 확인, 9.1절) | SLU |
| `Ui/UiElements.rsf` | UI 정점·픽셀 엔트리: 단색·이미지·9-slice·둥근 사각형 SDF(모서리 반지름 4개·테두리·그림자)·선(안티에일리어싱)·그라디언트, 비활성 회색 효과 | SLU |
| `Ui/GlyphSampling.rsh` | 글리프 atlas 표본: 회색조 coverage, 컬러(BGRA), SDF·MSDF(중앙값·화면 미분 기반 폭), 외곽선·그림자. `TextRenderComponent` 머티리얼도 이 함수를 쓴다 | SLU |
| `Ui/UiClipMask.rsf` | stencil clip(회전된 clip 사각형), 사각형 clip은 scissor | SLU |
| `Ui/UiPostEffects.rsf` | UI 배경 흐림(분리 Gaussian 재사용), 색각 이상 보정(`Color/ColorVisionDeficiency.rsh`) | SLU |
| `Ui/UiComposite.rsf` | UI 렌더 타깃을 장면 출력에 합성(SDR: 알파 합성. HDR UI 휘도·paper white는 HDR 후속) | SLU |
| `Ui/SimpleElements.rsf` | 단순 요소: 2D 선·삼각형·텍스처(채널 mask·mip·slice 고르기 — 텍스처 미리보기, 볼륨 텍스처 단면), hit proxy id 출력 | SL10(RN RS13)·SLU |

**단계.** SLU(UI 툴킷 UT2 — 렌더러 RS 단계와 독립, SH2·GX4 뒤), 단순 요소 편집 부분은 SL10(RN RS13).

**근거 문헌.** Green, *Improved Alpha-Tested Magnification for Vector Textures and Special Effects*, SIGGRAPH 2007 Course(SDF 글꼴); Chlumský, *Shape Decomposition for Multi-channel Distance Fields*, 석사 논문 2015(MSDF); Quílez, *2D Distance Functions*(둥근 사각형 SDF); Loop, Blinn, *Resolution Independent Curve Rendering using Programmable Graphics Hardware*, SIGGRAPH 2005(벡터 곡선 — SVG 후속 참고); Machado 외 2009(색각 이상, A03 참조).
