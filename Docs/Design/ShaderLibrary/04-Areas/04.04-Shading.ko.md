### 4.4 BRDF·셰이딩 모델·광원 적분(A04)

**역할.** 미세면 BRDF 항(분포·가시성·Fresnel)과 확산 항, 환경 BRDF(split-sum), 다중 산란 에너지 보존, `SurfaceAttributes`에서 셰이딩 파라미터를 만드는 규칙, shading model별 직접광 평가(`EvaluateDirectLighting`, RN 14.4절), 면광원(구·관·사각) 적분, 확산·반사 기여를 따로 모으는 누적기.

**UE 파일(21).** `BRDF.ush`, `ShadingCommon.ush`, `ShadingModels.ush`, `ShadingModelsMaterial.ush`, `ShadingModelsSampling.ush`, `ShadingEnergyConservation.ush`·`ShadingEnergyConservationTable.usf`·`ShadingEnergyConservationTemplate.ush`, `ShadingFurnaceTest.usf`, `ClearCoatCommon.ush`, `ThinFilmBSDF.ush`, `SGGX.ush`, `TransmissionCommon.ush`, `AreaLightCommon.ush`, `CapsuleLight.ush`·`CapsuleLightIntegrate.ush`·`CapsuleLightSampling.ush`, `RectLight.ush`·`RectLightIntegrate.ush`, `LightAccumulator.ush`, `MobileGGX.tps`(파일 `MobileGGX.ush`는 모바일 전용 제외, 1.4절).

**UE 5.8 근거 주의(결정 SLD3).** `ShadingModels.ush`의 shading model별 평가 함수, `ShadingModelsSampling.ush`, `RectLightIntegrate.ush`·`CapsuleLightIntegrate.ush`의 고전 적분 함수, `DeferredShadingCommon.ush`·`DeferredLightingCommon.ush`의 고전 경로에는 `UE_DEPRECATED 5.7 - Deprecated by Substrate` 표시가 있다. 5.8의 현재 경로는 Substrate(기본 Blendable GBuffer 모드에서는 closure 하나)다. Rocks는 deprecated 함수를 근거로 삼지 않는다.
- 근거로 쓰는 UE 위치: `BRDF.ush`(분포·가시성·Fresnel 항 — deprecated 표시 없음), `ShadingEnergyConservation*`, 그리고 Substrate의 slab 하나 평가(4.24절 A29 폴더의 `SubstrateEvaluation.ush`·`SubstrateLightingCommon.ush` 가운데 단일 slab 부분)의 **역할과 입출력**.
- Rocks 모델은 MS 결정 MD1(그래프는 Substrate형, 렌더러에는 `SurfaceAttributes`)과 같다. `SurfaceAttributes` 고전 입력(baseColor·metallic·specular·roughness)을 slab 파라미터(확산 albedo·F0·F90·roughness)로 바꿔 평가한다. Substrate의 다중 closure·layer 연산·tile 분류는 후속(A29)이다.

**의존.** A01·A02·A03(휘도). 쓰는 곳: A09(직접 조명), A11(IBL), A15(투명 조명), A23(고급 모델), A07(GBuffer 인코딩 전 파라미터). 내장 자원: RB 11.1절 기본 BRDF LUT(128×32 `RG16Float`), 에너지 보존 표(아래).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Shading/MicrofacetTerms.rsh` | GGX 분포(등방·이방), Smith 높이 상관 가시성과 그 근사, Schlick Fresnel(F0·F90)·정확한 유전체 Fresnel, inverse GGX·Charlie sheen 분포(옷감), roughness → α 사상과 하한(이름 있는 상수) | SL0 |
| `Shading/DiffuseTerms.rsh` | Lambert, Burley(재정규화), Chan 확산(roughness 의존 retro-reflection), wrap 조명(TwoSidedFoliage·Subsurface용) | SL0 |
| `Shading/EnvironmentBrdf.rsh` | split-sum 환경 BRDF: 내장 LUT 표본(텍스처는 인자로)과 해석적 근사(GLES·LUT 없는 경로) | SL0 |
| `Shading/EnergyConservation.rsh` | GGX 다중 산란 보정(방향 albedo E(μ)·평균 albedo 표 표본), 확산–반사 에너지 분배 | SL0 |
| `Shading/BuildEnergyTables.rsf` | 에너지 보존 표 생성 compute(내장 자원 팩 초기화 때 한 번, RB 6.3절). CPU 생성으로 대신할지는 SL3 착수 때 RB BRDF LUT와 같은 방식(CPU)으로 정한다 | SL3 |
| `Shading/SurfaceShading.rsh` | `SurfaceAttributes` → 셰이딩 파라미터(`DiffuseColor = baseColor·(1−metallic)`, `F0 = lerp(0.08·specular, baseColor, metallic)`, roughness 하한), shading model 번호 분기 골격(`MATERIAL_SINGLE_SHADING_MODEL`이면 그 분기만, RN 14.4절) | SL0(골격)·SL3 |
| `Shading/DirectLighting.rsh` | `EvaluateDirectLighting(shading, light sample) → {diffuse, specular, transmission}`: `Unlit`·`DefaultLit`(SL3), 고급 모델 분기는 A23 파일을 부른다 | SL3 |
| `Shading/LightAccumulation.rsh` | 확산·반사·투과 기여를 따로 모으는 누적기(화면 공간 SSS 분리 출력용), 휘도 기반 디버그 카운터 | SL3 |
| `Shading/SphereLightIntegration.rsh` | 구·관(capsule) 광원: 대표점 방법과 roughness 넓힘 에너지 정규화, source radius·length·soft radius | SL3 |
| `Shading/RectLightIntegration.rsh` | 사각 광원: LTC 적분(LTC 표는 내장 자원), barn door, 광원 텍스처 atlas 표본(A08) | SL10(RN RS9) |
| `Shading/ShadingTestKernels.rsf` | 시험 전용 엔트리: 백색 노 시험(furnace), BRDF 적분·상반성 확인을 GPU에서 돌리는 probe(8장). 엔진 내장 라이브러리에 넣지 않는다(시험 셰이더 루트) | SL0 |

**들이지 않는 것.** shading model별 importance sampling(`ShadingModelsSampling.ush`) — deprecated이고 쓰는 곳이 RT·PT(후속)다. 들일 때 Substrate slab 표본 기준으로 `Math/SampleWarping.rsh` 위에 만든다. `ThinFilmBSDF`(무지개빛 박막)·`SGGX`(microflake)는 MS 표면 범위 SF1–SF3에 없어 후속(SF4·볼륨)이다. `ClearCoatCommon`·`TransmissionCommon`은 A23(SL10)이다.

**단계.** SL0(BRDF 항·환경 BRDF·에너지 보존 표본·셰이딩 파라미터 골격 — CPU 대조 시험), SL3(DefaultLit 직접광 평가·구 광원·에너지 표 생성), SL10(사각 광원·고급 모델).
