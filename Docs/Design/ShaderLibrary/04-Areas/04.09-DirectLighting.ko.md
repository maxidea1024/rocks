### 4.9 직접 조명·Deferred 조명(A09)

**역할.** 한 픽셀에 대해 directional 목록 + light grid local 광원을 돌며 그림자·감쇠·BRDF를 합하는 **조명 함수**(Forward+ base pass·투명·Deferred 조명 pass가 같은 원문, RN 1·8.3·14.4절)와, 그것을 GBuffer 위에서 전체 화면으로 부르는 Deferred 조명 pass.

**UE 파일(5).** `DeferredLightingCommon.ush`, `DeferredLightPixelShaders.usf`, `DeferredLightVertexShaders.usf`, `DynamicLightingCommon.ush`, `ForwardLightingCommon.ush`. (`ForwardShadowingCommon.ush`는 A10, `ClusteredDeferredShading*`는 제외 — 1.4절.)

**UE 구조 메모.** UE 5.8 Deferred 기본은 광원마다 화면 사각형·광원 모양 메시를 그리는 pass(`DeferredLightVertexShaders`·`DeferredLightPixelShaders`)다. 고전 경로 함수(`DeferredLightingCommon.ush`의 일부)는 5.7 deprecated이고 Substrate 조명 함수로 넘어갔다. Forward는 `ForwardLightingCommon.ush`가 light grid를 순회한다.

**Rocks 차이(결정 RN1 따름).** Deferred도 광원별 pass가 아니라 **전체 화면 pass 하나**가 Forward+와 같은 조명 함수를 부른다. 그래서 광원 모양 메시 VS(`DeferredLightVertexShaders`)에 대응하는 파일이 없다. 대신 전체 화면 삼각형(A18)을 쓴다.

**의존.** A04(BRDF·`EvaluateDirectLighting`), A08(광원 기록·grid), A10(그림자 표본), A11(sky light·반사 — 간접 합성은 F12), A14(정적 그림자 인자), A06(view·장면 텍스처), A07(GBuffer 해독). 렌더러: RN 7.3절 `DeferredLightingPass`, 8.3절 base pass 조명 평가, 6.2절 F9·F11, RS1·RS2.

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Lighting/ForwardLighting.rsh` | 조명 함수 본체: directional 목록 → light grid 셀 순회 → 광원마다 감쇠·그림자(A10 직접 표본)·`EvaluateDirectLighting` 누적, sky light 상수(SH) 기여, 정적 조명 표본 연결 자리. shading model 분기는 A04 골격 | SL3 |
| `Lighting/DeferredLightingPass.rsf` | 전체 화면: GBuffer 해독 → 같은 조명 함수 → SceneColor 가산. 모든 shading model 분기 포함(머티리얼 없는 엔진 셰이더, RN 14.4절). GLES 4 MRT 다중 pass 변형(RN RS2 (c)) | SL4 |
| `Lighting/LightingDebugCounters.rsh` | 픽셀당 광원 수·넘침 셀 표시(디버그 view, A20) | SL3 |

**단계.** SL3(RN RS1), SL4(RN RS2).

**근거 문헌.** Harada 외 2012·Olsson 외 2012(A08 참조); Lagarde, de Rousiers 2014; Karis 2013(A04 참조); Hoffman, *Physics and Math of Shading*, SIGGRAPH 2015 Course.
