# 셰이더 라이브러리 — 4.22 스키닝·정점 변형(A22)

[4장 목차](README.ko.md)

### 4.22 스키닝·정점 변형(A22)

**역할.** skinned 메시의 정점 입력 타입(본 행렬 typed buffer에서 현재·이전 pose 합성), GPU skinning 결과 캐시(compute skinning → 정점 버퍼, 이전 위치 보존), morph target 희소 목록 적용, skinning 뒤 tangent 재계산, 본 transform 해독.

**UE 파일(17).** `GpuSkinVertexFactory.ush`, `GpuSkinCommon.ush`, `GpuSkinCacheComputeShader.usf`, `BoneTransform.ush`, `MorphTargets.usf`, `RecomputeTangentsCommon.ush`, `RecomputeTangentsPerTrianglePass.usf`, `RecomputeTangentsPerVertexPass.usf`, `Skinning/SkinningDataDecode.ush`·`SkinningSceneDataDecode.ush`·`TransformProviders.usf`·`AnimSequenceTransformProvider.usf`·`AnimBankEval.usf`·`CopyPreviousTransforms.usf`·`ResolveAttachments.usf`·`SkinnedMeshDebug.usf`, `Shared/SkinningDefinitions.h`.

**의존.** A05(정점 입력 인터페이스), A06(GPU Scene), A02(quaternion·패킹), A21(scan — morph 희소 목록). 렌더러: RN RS12(본 행렬은 LOD 통합 bone map 기준 `RGBA32Float` typed buffer에 현재·이전 pose, 섹션 분할 없음 — RB 결정 R18, morph 희소 목록 적용 — MeshAnimationAssets MR2). 컴포넌트: `SkinnedMeshComponent`·`SkeletalMeshComponent`·`PoseableMeshComponent`(CC CM7), `InstancedSkinnedMeshComponent`(CM11).

**Rocks 파일.**

| 파일 | 내용 | 단계 |
|---|---|---|
| `Skinning/BoneTransforms.rsh` | 본 행렬 typed buffer 읽기(3×4 행 우선, 현재·이전), 가중 합성(4·8 영향), 패킹 가중 해독 | SL10 |
| `VertexInput/SkinnedMeshVertexInput.rsh` | skinned 정점 입력 타입: 위치·법선·tangent skinning, 이전 pose 위치(velocity), 캐시가 켜지면 캐시 정점 읽기 | SL10 |
| `Skinning/SkinningCache.rsf` | compute skinning → 정점 버퍼(그림자·velocity·여러 pass 재사용), 이전 위치 버퍼 교대 | SL10 |
| `Skinning/ApplyMorphTargets.rsf` | morph 희소 delta 누적(정점별 원자 합 또는 정렬 뒤 scan — 결정적 순서), 법선 delta 정규화 | SL10 |
| `Skinning/RecomputeTangents.rsf` | 삼각형 단위 누적 → 정점 단위 정규화(morph·cloth 뒤 tangent 재계산) | SL10 |
| `Shared/SkinningLayout.h` | 3.3절 | SL10 |

**들이지 않는 것(지금).** 애니메이션 bank GPU 평가(`AnimBankEval.usf`·`AnimSequenceTransformProvider.usf`·`TransformProviders.usf` — 인스턴스드 skinned 메시, CC CM11), GPU 부착 해석(`ResolveAttachments.usf`), skinned 메시 디버그(`SkinnedMeshDebug.usf`)는 인스턴스드 skinned 메시·애니메이션 bank 단계와 함께 후속.

**단계.** SL10(RN RS12).

**근거 문헌.** Magnenat-Thalmann, Laperrière, Thalmann, *Joint-Dependent Local Deformations for Hand Animation and Object Grasping*, GI 1988(선형 블렌드 skinning); Kavan, Collins, Žára, O'Sullivan, *Geometric Skinning with Approximate Dual Quaternion Blending*, ACM TOG 2008(후속 선택); Lengyel, *Computing Tangent Space Basis Vectors for an Arbitrary Mesh*, 2001; Mikkelsen 2008(A05 참조).
