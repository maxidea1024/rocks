객체 모델구현

반쯤 만든 객체는 세상에 나오지 않는다

객체는 비공개로 만들고, 참조 간선을 모두 검증한 뒤 한꺼번에 공개한다. 중간에 하나라도 실패하면 만든 순서의 역순으로 되돌리므로, 다른 코드가 미완성 객체를 보는 일이 없다.

Outer와 이름생성 때 정하고 바꾸지 않는다. 경로로 어느 객체든 찾는다.

리플렉션구현

C++ 선언 한 줄이 엔진 전체와 연결된다

풍부한 값 종류정수·실수·문자열·Name·Guid·해시, 배열·Optional·Map·Set, 구조체 상속, InstancedStruct.

Sparks — 게임을 멈추지 않고 코드를 바꾼다

Sparks는 프로그래머가 아니어도 읽고 쓸 수 있는 단순한 정적 타입 언어다. 파괴된 객체 참조는 null이 되고, 메모리·리소스 누수는 언어 구조상 생길 수 없다. 성능이 중요한 부분은 C++로, 게임 흐름은 Sparks로 나눠 쓴다.

    }

게임 로직의 대부분은 기다리고 반응하는 일이다. Sparks는 async·await와 이벤트를 언어에 넣어, 콜백 지옥이나 상태 플래그 없이 위에서 아래로 읽히는 코드로 쓴다. 취소와 자원 정리는 엔진이 맡는다.

class DoorLogic : ScriptableComponent {
    @net var State = DoorState.Closed;          // 서버에서 복제
    event Opened(by: Actor?);

    @skipWhileBusy                              // 여는 동안 온 요청은 버린다
    on Owner.Interacted(actor: Actor) {
        State = DoorState.Opening;
        await Delay(SwingSeconds, Clock.Game);  // 게임 시계로 기다린다
        State = DoorState.Open;
        emit Opened(actor);                     // 이벤트 발행
    }

    on State.Changed() { ApplyPose(); }         // 값이 바뀌면 모든 기기에서

    @skipWhileBusy
    on TriggerEnter(other: Actor) {
        let seq = try await Cutscene.Load();    // 비동기 로드, 실패는 try
        await World.Sequencer.Prepare(seq);     // mip·오디오 미리 상주
        await Race(World.Sequencer.Play(seq), Skip.Triggered);
    }                                           // 먼저 끝난 쪽만 남고 나머지는 취소
}

에디터를 떠나지 않고 지금 만든 레벨을 바로 플레이한다. 서버와 클라이언트를 한꺼번에 띄우고, 멈추고, 한 tick씩 넘기고, 실행 중에 고친 값을 골라 원본에 되돌린다. 1,000번을 시작하고 멈춰도 메모리와 GPU가 처음 상태로 돌아오는 것이 완료 기준이다.

이미 언리얼 엔진으로 만든 콘텐츠를 버릴 필요가 없다. 언리얼 에디터에 설치하는 RocksExport 플러그인이 에셋을 교환 묶음으로 내보내고, Rocks 임포터가 받아 Rocks 에셋으로 만든다. Rocks는 언리얼과 같은 좌표계(왼손, +Z 위)와 단위(cm, 도)를 쓰므로 변환 과정이 없고 손실도 없다.

에셋 비동기 로딩구현

게임을 멈추지 않고 에셋이 들어온다

요청한 에셋의 의존 묶음을 매니페스트에서 계산하고, 파일 읽기와 검증·압축 해제는 IO와 worker가 맡는다. 게임 lane은 프레임 예산 안에서 완성된 묶음을 한 트랜잭션으로 공개만 한다. 반쯤 로드된 에셋은 보이지 않는다.

텍스처 스트리밍설계 완료 · 단계적 구현

보이는 만큼의 해상도만, 메모리에

장면에서 텍스처가 쓰이는 곳마다 필요한 mip을 계산해, 예산 안에서 무엇을 몇 mip 상주시킬지 정한다. 계산은 결정적인 CPU 작업이고, 실제 전송은 IO·업로드·교체로 따로 실행한다. 교체는 프레임 경계에서 게시하므로 그리는 도중에 텍스처가 바뀌지 않는다.

레벨 스트리밍설계 완료 · 단계적 구현

끝없는 월드, 필요한 셀만

월드를 격자 셀로 나누고, 플레이어와 카메라 같은 스트리밍 원천 주변의 셀만 불러온다. 셀은 렌더·충돌·내비게이션 준비가 모두 끝난 tick 경계에서만 활성화되므로, 아직 충돌이 없는 땅을 밟는 일이 없다.

데이터 층같은 공간에 낮·밤, 퀘스트 단계 같은 층을 겹쳐 켜고 끈다.
HLOD먼 셀은 묶은 저해상도 대리 모델로. 재생성 범위는 의존 그래프로 추적.
순간 이동목적지 미리 불러오기와 commit gate로 빈 세상이 보이지 않게.
셀 경계 진단셀을 넘는 강한 참조는 쿠커가 진단해 월드 전체 상주를 막는다.
